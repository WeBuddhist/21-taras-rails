# Audience profile: literal-keyword

**Purpose-built profile for machine consumption, not human readers.** The translation's sole
audience is the keyword-extraction pipeline
(`4-SYSTEM/Guidelines/keyword-extraction-methodology.md`, Step 0–1): TF-IDF/YAKE candidate
detection over English, followed by per-occurrence en→bo mapping back onto the Tibetan blocks.

Priorities, in order: **lexical completeness** (every Tibetan content word gets an explicit
English rendering — nothing paraphrased away), **consistency** (the same Tibetan term is
rendered the same way at every occurrence), **line fidelity** (pada-aligned: one English line
per Tibetan line, same block IDs), and only then readability. Elegance is a non-goal; a
stilted but word-faithful line beats a fluent one that absorbs a keyword into a paraphrase.
Mantra syllables stay as transliteration (OṂ, TUTTĀRA, TURE, HŪṂ, SVĀHĀ, PHAṬ), proper names
as standard transliteration (Tārā, Amitābha, Meru, Mandāra, Vindhya), technical vocabulary as
its most common lexical equivalent rather than an interpretive gloss.
