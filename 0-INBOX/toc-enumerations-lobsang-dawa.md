སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པ་འདི་འཆད་པ་ལ་གསུམ།མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ། མཇུག་བསྡུ་བའོ།
Enumeration Block 2:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ་གསུམ། ལོ་རྒྱུས་ཀྱི་སྒོ་ནས་བསྟོད་པ་དང་། སྐུའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ། འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པའོ།
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། ལོངས་སྐུའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་དང་། ཆོས་སྐུའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པའོ། །དང་པོ་ལ་གཉིས། ཞི་བའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་དང་། ཁྲོ་མོའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པའོ། །དང་པོ་ལ་དྲུག ཞལ་མདངས་གསལ་ཞིང་འོད་ཟེར་འཕྲོ་བའི་སྒོ་ནས་བསྟོད་པ་དང་། སྐུ་མདོག་ཕྱག་མཚན་དང་རྒྱུའི་སྒོ་ནས་བསྟོད་པ། རྒྱལ་བ་དང་རྒྱལ་སྲས་ཀྱིས་གུས་པར་བསྟེན་པའི་སྒོ་ནས་བསྟོད་པ། མི་མཐུན་ཕྱོགས་གནོན་པའི་སྒོ་ནས་བསྟོད་པ། འཇིག་རྟེན་པའི་ལྷ་ཆེན་པོ་རྣམས་ཀྱིས་བཀུར་བའི་སྒོ་ནས་བསྟོད་པ། ཕ་རོལ་འཇོམས་པའི་སྒོ་ནས་བསྟོད་པའོ།།
Enumeration Block 4:
གཉིས་པ་ཁྲོ་མོའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་ལ་བདུན། བདུད་དང་སྒྲིབ་གཉིས་སྦྱོང་བའི་སྒོ་ནས་བསྟོད་པ་དང་། ཕྱག་མཚན་གྱི་སྒོ་ནས་བསྟོད་པ། དབུ་རྒྱན་དང་བཞད་སྒྲའི་སྒོ་ནས་བསྟོད་པ། ཕྱོགས་སྐྱོང་གིས་འཕྲིན་ལས་སྒྲུབ་པའི་སྒོ་ནས་བསྟོད་པ། དབུ་རྒྱན་གྱི་སྒོ་ནས་བསྟོད་པ།དྲག་པོའི་བཞུགས་ཚུལ་གྱི་སྒོ་ནས་བསྟོད་པ། ཧཱུཾ་ཡིག་ལས་འོད་ཟེར་འཕྲོས་པའི་སྒོ་ནས་བསྟོད་པའོ།།
Enumeration Block 5:
གསུམ་པ་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ལ་དྲུག ཞི་ཁྲོའི་སྔགས་ཀྱི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་དང་། ཁྲོ་མོས་ས་གསུམ་གཡོ་བའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ། བརྟན་གཡོའི་དུག་རྣམས་སེལ་བའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ། རྩོད་པ་དང་རྨི་ལམ་ངན་པ་སེལ་བའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ། རིམས་ནད་སེལ་བའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ། གདོན་དང་རོ་ལངས་འཇོམས་པའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པའོ།།
