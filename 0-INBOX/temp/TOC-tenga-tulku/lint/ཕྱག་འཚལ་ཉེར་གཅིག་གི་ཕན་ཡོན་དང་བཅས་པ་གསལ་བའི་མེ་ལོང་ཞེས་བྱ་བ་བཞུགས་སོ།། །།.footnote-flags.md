# Footnote-number flags — ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཕན་ཡོན་དང་བཅས་པ་གསལ་བའི་མེ་ལོང་ཞེས་བྱ་བ་བཞུགས་སོ།། །།.md

Each row is a digit run found glued to the running text (a flattened
footnote marker). Block IDs (`^1-1`) are excluded by construction.

**Validation:** genuine footnotes form one unbroken ascending run, so
any gap or duplicate below is a red flag to inspect.

```
No candidates found.
```

To reject a false positive, set its `approve` column to `N` in
`ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཕན་ཡོན་དང་བཅས་པ་གསལ་བའི་མེ་ལོང་ཞེས་བྱ་བ་བཞུགས་སོ།། །།.footnote-flags.tsv`, then run the remover.
