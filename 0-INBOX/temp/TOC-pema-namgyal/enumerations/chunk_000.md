Enumeration Block 1:
སྦྱོར་དངོས་མཇུག་གསུམ་ལས། དང་པོ་སྦྱོར་བ་ཚོགས་བསགས་ཀྱི་རིམ་པ་ལ་ཚོགས་ཞིང་སྤྱན་འདྲེན་པ་ནི།
Enumeration Block 2:
ཚོགས་བསགས་དངོས་ལ་ཡན་ལག་བདུན་ལས། དང་པོ་ལུས་དཔག་ཏུ་མེད་པར་སྤྲུལ་ནས་ཕྱག་འཚལ་བ་ནི།
Enumeration Block 3:
གཉིས་པ་རྗེ་བཙུན་མ་ལ་མཆོད་པ་འབུལ་བའི་ཡན་ལག་ནི།
Enumeration Block 4:
གསུམ་པ་རང་གཞན་གྱི་སྡིག་པ་བཤགས་པའི་ཡན་ལག་ནི།
Enumeration Block 5:
བཞི་པ་རང་གཞན་གྱིས་དགེ་བ་བསྒྲུབས་པ་ལ་རྗེས་སུ་ཡི་རང་བའི་ཡན་ལག་ནི།
Enumeration Block 6:
ལྔ་པ་ཆོས་ཀྱི་འཁོར་ལོ་བསྐོར་དུ་གསོལ་བའི་ཡན་ལག་ནི།
Enumeration Block 7:
དྲུག་པ་སྐུ་མྱ་ངན་ལས་མི་འདའ་བར་གསོལ་བ་འདེབས་པའི་ཡན་ལག་ནི།
Enumeration Block 8:
བདུན་པ་བསྔོ་སྨོན་ཡན་ལག་ནི། དེའང་ཡན་ལག་དང་པོ་གཉིས་ཀྱི་སྒོ་ནས་ཚོགས་བསགས། གསུམ་པས་སྡིག་སྒྲིབ་སྦྱངས། ལྷག་མ་གསུམ་གྱིས་གོང་དུ་སྤེལ་བ་བཅས་བསགས་སྦྱངས་སྤེལ་གསུམ་གྱི་དགེ་བ་ཐམས་ཅད་
Enumeration Block 9:
དང་པོ་མཚན་རྒྱ་གར་སཾ་སྐྲྀ་ཏའི་སྐད་དུ་སྨོས་ན། ན་མཿཏཱ་ར་ཨེ་ཀ་བིམ་ཤ་ཏི་སྟོ་ཏྲ་གུ་ཎ་ཧི་ཏ་ས་ཀ གཉིས་པ་བོད་སྐད་དུ་སྨོས་ན། སྒྲོལ་མ་ལ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གིས་བསྟོད་པ་ཕན་ཡོན་དང་བཅས་པ།གསུམ་པ་སྐད་གཉིས་ཤན་སྦྱར་དུ་སྨོས་ན། ན་མཿནི་ཕྱག་འཚལ། ཏཱ་ར་ནི་སྒྲོལ་མ། ཨེ་ཀ་བིཾ་ཤ་ཏི་ནི་ཉི་ཤུ་རྩ་གཅིག་གིས། སྟོ་ཏྲ་ནི་བསྟོད་པ།གུ་ཎ་ཧི་ཏ་ས་ཀ་ནི་ཕན་ཡོན་དང་བཅས་པའོ། བཞི་པ་མཚན་དོན་དངོས་བསྟན་ལྟར་གོ་སླའོ།
