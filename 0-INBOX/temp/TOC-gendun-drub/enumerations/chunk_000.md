Enumeration Block 2:
གཉིས་པ་ལ། རྩ་བའི་སྔགས་ཀྱིས་བསྟོད་པ་འདི་དང་། །ཕྱག་འཚལ་བ་ནི་ཉི་ཤུ་རྩ་གཅིག །ཅེས་གཉིས་སུ་ཕྱེ་བའི།
Enumeration Block 3:
དེས་ན། མདོར་བསྟན་པ་རྒྱས་པར་བཤད་པ། ཕན་ཡོན་བསྟན་པ་དང་གསུམ།
Enumeration Block 4:
གཉིས་པ་ལ། ལོ་རྒྱུས་ཀྱི་སྒོ་ནས་བསྟོད་པ་དང་སྐུའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ། འཕྲིན་ལས་ཀྱི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་དང་གསུམ།
Enumeration Block 5:
གཉིས་པ་ལ། ལོངས་སྐུའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་དང་། ཆོས་སྐུའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་གཉིས། དང་པོ་ལ། ཞི་བའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་དང་། ཁྲོ་མོའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་གཉིས། དང་པོ་ལ། ཕྱག་འཚལ་དྲུག་ཡོད་པའི།
Enumeration Block 6:
