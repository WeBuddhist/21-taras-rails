Enumeration Block 1:
ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གིས་བསྟོད་པ་ལ་མདོར་བསྟན། རྒྱས་བཤད། ཕན་ཡོན་བསྟན་པས་མཇུག་བསྡུ་བ་གསུམ་ལས།
Enumeration Block 2:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ལའང་། སྤྱིར་ལོ་རྒྱུས་ཀྱི་དབང་དུ་བྱས་ཏེ་ཕྱག་འཚལ་བ། སྐུའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ། ཕྲིན་ལས་བསྟན་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ།
Enumeration Block 3:
གཉིས་པ་སྐུའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་ལ། ལོངས་སྐུའི་རྣམ་པ་དང་། ཆོས་སྐུའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་གཉིས། དང་པོ་ལོངས་སྐུའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་ལའང་ཞི་བའི་རྣམ་པ་དང་།ཁྲོ་བོའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་གཉིས་ལས། དང་པོ་ཞི་བའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་ལ། ཕྱག་འཚལ་དྲུག་གི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ལ།
Enumeration Block 4:
ཕྱག་འཚལ་བ་ལ་ཡོན་ཏན་གང་དང་ལྡན་ན། རྒྱལ་བ་སངས་རྒྱས་དང་བྱང་ཆུབ་སེམས་དཔའ་ཆེན་པོ་རྣམས་ཀྱིས་གུས་པས་བསྟེན་ཅིང་ཕྱག་འཚལ་བས་ཕྱག་འཚལ་བའི་ཡུལ་དུ་གྱུར་པ་དང་། དེ་ལའང་སངས་རྒྱས་ཀྱིས་གུས་པས་བསྟེན་པའི་ཚུལ་དང་། བྱང་སེམས་ཆེན་པོ་རྣམས་ཀྱིས་གུས་པས་བསྟེན་པའི་ཚུལ་སྟེ་རྣམ་པ་གཉིས་ལས།

Enumeration Block 2:

Enumeration Block 3:

Enumeration Block 1:
ཕྱག་འཚལ་བ་ཉི་ཤུ་རྩ་གཅིག་ནི། དང་པོ་ལོ་རྒྱུས་ཀྱི་སྒོ་ནས་ཕྱག་འཚལ་བ་གཅིག སྐུའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་ལ་ཞི་བའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་དྲུག་དང་། ཁྲོ་བོའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་བདུན། ཆོས་སྐུའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་གཅིག ཕྲིན་ལས་ཀྱི་ཡོན་ཏན་བསྟན་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་དྲུག་སྟེ།
Enumeration Block 2:
གསུམ་པ་ཕན་ཡོན་བསྟན་པའི་སྒོ་ནས་མཇུག་བསྡུ་བ་ལའང་རྣམ་པ་བཞི་སྟེ། བསམ་པ་བསྟན་པ་དང་། དུས་བསྟན་པ་དང་། ཕན་ཡོན་དངོས་བསྟན་པ། གྲངས་ཀྱི་སྒོ་ནས་མཇུག་བསྡུ་བ་སྟེ་བཞི་ལས།
