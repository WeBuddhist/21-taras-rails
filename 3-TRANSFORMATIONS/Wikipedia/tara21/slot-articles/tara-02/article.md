'''བློ་གཏེར་དབྱངས་ཅན་མ་'''ནི་སྒྲོལ་མར་ཕྱག་འཚལ་ཉེར་གཅིག་གིས་བསྟོད་པའི་གཉིས་པའི་ཕྱག་འཚལ་ཡིན།<ref name="taranatha">ཏཱ་ར་ནཱ་ཐ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།</ref><ref name="sungrab-tulku">འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།</ref><ref name="tenzin-dhonzang">སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།</ref> རྩ་བའི་ཚིགས་བཅད་ལས།

"ཕྱག་འཚལ་སྟོན་ཀའི་ཟླ་བ་ཀུན་ཏུ། ། གང་བ་བརྒྱ་ནི་བརྩེགས་པའི་ཞལ་མ། ། སྐར་མ་སྟོང་ཕྲག་ཚོགས་པ་རྣམས་ཀྱིས།། རབ་ཏུ་ཕྱེ་བའི་འོད་རབ་འབར་མ།"<ref name="yama-sonam">རྗེ་བཙུན་ཡ་མ་བསོད་ནམས། སྒྲོལ་མ་ཉེར་གཅིག་པའི་བསྟོད་འགྲེལ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།</ref>

ཞེས་གསུངས་པ་ལྟར་ཞལ་རས་སྟོན་ཀའི་ཟླ་བ་བརྒྱ་བརྩེགས་པ་ལྟ་བུར་དཀར་ཞིང་མཛེས་ལ་འོད་ཟེར་སྐར་མ་སྟོང་ཕྲག་ལས་ཀྱང་ལྷག་པར་གསལ་བའི་ལྷ་མོར་མཐའ་དག་གིས་ངོས་འཛིན་བྱེད།།<ref name="dharmabhadra">དངུལ་ཆུ་དྷརྨ་བྷ་དྲ། སྒྲོལ་མར་ཕྱག་འཚལ་ཉེར་གཅིག་གིས་བསྟོད་པའི་རྣམ་བཤད་ཡིད་འཕྲོག་ཨུཏྤལའི་ཆུན་པོ།</ref>

== མཚན་གྱི་ངེས་ཚིག ==
འདིའི་མཚན་ལ་གཞུང་ལུགས་སོ་སོས་མི་འདྲ་བར་གདགས་ཏེ་མཚན་གཅིག་ཏུ་མ་གྲུབ། བློ་གཏེར་དབྱངས་ཅན་མ་ཞེས་མཚན་གྱིས་གདགས་སོ།།<ref name="palden-sherab">མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ།</ref><ref name="sangye-nyentrul">སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ། རྗེ་བཙུན་མ་སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་འགྲེལ་དང་དམིགས་རིམ་འཕགས་མའི་བྱིན་རླབས་གྲུ་ཆར།</ref><ref name="tsultrim-namdak">མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག ། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།</ref>

འོན་ཀྱང་རྒྱལ་བ་དགེ་འདུན་གྲུབ་ཀྱིས་རང་ཉིད་ཀྱི་འགྲེལ་བར།

"འདི་ལ་དཀར་མོ་མདངས་ལྡན་སྒྲོལ་མ་ཞེས་བཤད་དོ།"<ref name="gendun-drub">རྒྱལ་བ་དགེ་འདུན་གྲུབ (ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་དང་པོ)། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཊཱིཀྐ་རིན་པོ་ཆེའི་ཕྲེང་བ།</ref>

ཞེས་གསུངས་ཤིང་རྗེ་བཙུན་ཡ་མ་བསོད་ནམས་ཀྱི་འགྲེལ་བ་ཞིག་གིས་ཀྱང་འདི་ཉིད་རྒྱལ་བ་དགེ་འདུན་གྲུབ་ཀྱི་ལུགས་སུ་ངོས་འཛིན་བྱེད་དོ།།<ref name="yama-sonam" />

བསྟན་འཛིན་དོན་བཟང་གིས་ནི་ཞི་བ་ཆེན་མོ་ཞེས་གདགས་ཤིང<ref name="tenzin-dhonzang" /> དགེ་བཤེས་བློ་བཟང་ཟླ་བའི་མཆན་འགྲེལ་ལྟར་ན་མཚན་གསར་དུ་མི་གདགས་པར་རྩ་ཚིག་ཉིད་ཀྱི་མཇུག་གི་ཚིག་འོད་རབ་འབར་མ་ཞེས་པ་ཉིད་ལས་མཚན་དུ་བཟུང་ངོ་།།<ref name="lobsang-dawa">དགེ་བཤེས་བློ་བཟང་ཟླ་བ། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་མཆན་འགྲེལ།</ref>

== སྐུ་ཡི་རྣམ་པ། ==
ལྷ་མོ་འདིའི་ཞལ་རས་སྟོན་ཀའི་ཟླ་བ་བརྒྱ་བརྩེགས་པ་ལྟ་བུར་དཀར་ཞིང་མཛེས་ཤིང<ref name="yama-sonam" /><ref name="karma-maitri">ཀརྨ་མཻ་ཏྲི། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པའི་བསྡུས་འགྲེལ།</ref><ref name="taranatha" /> སྐུ་མདོག་ཡང་དཀར་པོར་མཐུན་པར་བཤད་དོ།<ref name="sangye-nyentrul" /><ref name="palden-sherab" /><ref name="taranatha" /> སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ་དང་མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་གཉིས་ཀྱི་ལུགས་ལྟར་ན་ཞལ་གཅིག་ཕྱག་གཉིས་ཀྱི་ཞི་བའི་སྐུར་ཞབས་ཕྱེད་སྐྱིལ་གྱིས་པད་ཟླའི་སྟེང་དུ་བཞུགས་ཤིང་ཕྱག་གཡས་མཆོག་སྦྱིན་ཕྱག་རྒྱ་བཅས་ཏེ་ཕྱག་གཡོན་གྱིས་མེ་ལོང་ས་བོན་ཡིག་གིས་མཚན་པའི་ཨུཏྤལ་འཛིན་པར་གྲགས་སོ།།<ref name="sangye-nyentrul" /><ref name="palden-sherab" />

རྗེ་བཙུན་ཡ་མ་བསོད་ནམས་ཀྱི་འགྲེལ་བ་ཞིག་གིས་ནི་ཉི་མ་སྦས་པའི་གསུང་ལ་བརྟེན་ནས་སྐུའི་རྣམ་པ་གཞན་ཞིག་ཀྱང་བཤད་དེ།

"ཞལ་གསུམ་དཀར་སྔོ་གསེར་མདོག་ཅན། ། བཅུ་གཉིས་ཕྱག་མངའ་མཉམ་གཞག་དང་། ། ཁ་ཊཱཾ་འཁོར་ལོ་རིན་ཆེན་ཉིད། ། རྡོ་རྗེ་མེ་ཏོག་ཕྲེང་འཛིན་གཡས། ། རིལ་བ་ཨཏྤལ་དྲིལ་བུ་དང་། ། བུམ་པ་དང་ནི་པོ་ཏི་གཡོན།"<ref name="yama-sonam" />

ཞེས་གསུངས་ཏེ་ཞལ་གསུམ་ཕྱག་བཅུ་གཉིས་ཀྱི་སྐུར་ཡང་བཤད་དོ། འགྲེལ་པ་གཞན་རྣམས་ཀྱིས་ནི་ཚིག་རྐང་འདིའི་སྐབས་སུ་ཞལ་ཕྱག་གྲངས་ལ་ལུང་མི་སྟོན་ཏེ་སྐུའི་རྣམ་པ་རྒྱས་པ་འདི་རྗེ་བཙུན་ཡ་མ་བསོད་ནམས་ཀྱི་འགྲེལ་བ་གཅིག་པུས་གསུངས་པའི་ཁྱད་ཆོས་ཤིག་ཡིན་ནོ།།

== ཕྲིན་ལས་དང་ནུས་མཐུ། ==
མེ་ལོང་ནས་འཕྲོས་པའི་འོད་ཟེར་གྱིས་སེམས་ཅན་གྱི་མ་རིག་པའི་མུན་པ་སེལ་བར་བཤད་དེ<ref name="palden-sherab" /><ref name="sangye-nyentrul" /><ref name="tenzin-dhonzang" /> སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ་ལྟར་ན་འདིས་ཤེས་རབ་ཀྱི་སྟོབས་འཕེལ་ཞིང་བློ་གྲོས་རྒྱས་པར་བྱེད།།<ref name="sangye-nyentrul" />

ཟུར་མང་མཁན་པོ་པདྨ་རྣམ་རྒྱལ་གྱི་འགྲེལ་བར་ནི་བདུད་རྩིའི་འོད་རང་ལ་ཐིམ་པར་བསྒོམས་ན་ཚེ་དང་ཡེ་ཤེས་ཀྱི་དངོས་གྲུབ་ཐོབ་པར་བཤད།།<ref name="pema-namgyal">ལྡོམ་བུ་བ་པདྨ་རྣམ་པར་རྒྱལ་བ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་བདུད་རྩིའི་དགའ་ཚལ།</ref>

སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་གི་འགྲེལ་བར་ནི་གཞུང་འདིར་ཐུན་མོང་མ་ཡིན་པའི་གླུད་ཀྱི་ཉམས་ལེན་ཞིག་བཤད་དེ་རང་གི་ཉེས་ལྟུང་སྡིག་སྒྲིབ་བག་ཆགས་དང་བཅས་པ་བླ་མའི་སྐུ་གླུད་དང་བཅས་འཆི་བདག་གི་ཁར་གླུད་དུ་འབུལ་བས་ལན་ཆགས་ཐམས་ཅད་ཚིམ་པར་བཤད་ཅིང<ref name="tenzin-dhonzang" /> བྱམས་སྙིང་རྗེ་བྱང་ཆུབ་ཀྱི་སེམས་ནི་འཆི་བླུའི་མཆོག་ཏུ་བཤད་ལ་ལྷ་མོ་འདིའི་འཕྲིན་ལས་ཀྱི་གཙོ་བོ་ནི་གདོན་བགེགས་ཀྱི་གནོད་པ་དང་ལུས་སེམས་ཀྱི་ན་ཟུག་སེལ་བར་བཤད་དོ།།<ref name="tenzin-dhonzang" />

== སྦས་དོན་གྱི་བཤད་པ། ==
ཇོ་ནང་ཏཱ་ར་ནཱ་ཐ་དང་མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་གཉིས་ཀྱིས་རྫོགས་རིམ་གྱི་སྒོ་ནས་སྦས་དོན་ཞིག་ཀྱང་བཤད་དེ་ཟླ་བ་བརྒྱ་བརྩེགས་པ་ནི་བྱང་ཆུབ་སེམས་ནོར་བུ་ནས་སྤྱི་བོའི་བར་འཕོ་མེད་དུ་བརྩེགས་པའི་དོན་དང་སྐར་མ་སྟོང་ཕྲག་ནི་རྩ་ཕྲན་ཐམས་ཅད་ཁྱབ་པའི་དོན་དུ་བཤད་དོ།།<ref name="taranatha" /><ref name="palden-sherab" />

མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་ཁོ་ནས་འདི་ལ་བདེ་སྟོང་ལྷན་ཅིག་སྐྱེས་པའི་ཡེ་ཤེས་ཀྱིས་འཁོར་ལོ་བཞིའི་སྒོ་ནས་ཁྱབ་པར་ཡང་བཤད།<ref name="palden-sherab" /> བསྐྱེད་རིམ་གྱི་དམིགས་པར་རྡོ་རྗེ་དབྱངས་ཅན་མ་དཀར་མོ་ཡེ་ཤེས་མཚོ་རྒྱལ་གྱི་ཐུགས་ཀར་བཞུགས་པར་བཤད་ལ<ref name="palden-sherab" /> མཐར་ཐུག་གི་དོན་དུ་ནི་རྡོ་རྗེ་ཕག་མོ་དཀར་མོའི་རང་ཞལ་སྟོན་ཟླ་བརྩེགས་པ་ལྟ་བུར་ངོ་སྤྲོད་བྱེད་དོ།།<ref name="palden-sherab" />

== གཞུང་ལུགས་སོ་སོའི་བཤད་པ། ==
རྩ་ཚིག་"རབ་ཏུ་ཕྱེ"ཞེས་པའི་དོན་ལའང་གཞུང་ལུགས་མི་འདྲ་བ་ཡོད་དེ་མང་ཆེ་བས་ཞལ་གྱི་འོད་ཟེར་སྐར་མ་སྟོང་ཕྲག་ལས་ཀྱང་ལྷག་པར་གསལ་བའི་དོན་དུ་བཤད་ན<ref name="gendun-drub" /><ref name="drakpa-gyaltsen">རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།</ref><ref name="taranatha" /> རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོས་ནི་སྐར་མས་བརྒྱན་པའི་དོན་དུ་བཤད་དོ།<ref name="gendun-gyatso">རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོ (ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་གཉིས་པ)། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་མའི་རྣམ་བཤད།</ref> རྗེ་བཙུན་ཡ་མ་བསོད་ནམས་ཀྱི་འགྲེལ་བ་ཞིག་གིས་ནི་སྔ་མའི་འགྲེལ་མཛད་རྣམས་ལ་སྐྱོན་དུ་བརྗོད་དེ་སྐར་འོད་ནི་འོད་ཆུང་ངུའི་དཔེ་ཡིན་པས་ལྷ་མོའི་ཞལ་དང་སྦྱར་ན་སྨད་པའི་རྒྱན་དུ་འགྱུར་བར་བཤད་ཅིང་རང་ཉིད་ཀྱིས་"རབ་ཏུ་ཕྱེ"ཞེས་པ་ཟླ་འོད་དམིགས་སུ་ཕྱེ་བའི་དོན་དུ་འཆད་དོ།།<ref name="yama-sonam" />

འོད་ཟེར་གྱི་ཡོན་ཏན་གང་ཞིག་གི་རྟགས་སུ་གྱུར་པའང་གཞུང་ལུགས་མི་འདྲའོ། མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་དང་སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ་གཉིས་ཀྱིས་སོ་སོ་ཡང་དག་པའི་རིག་པ་བཞི་སྟེ་དོན་དང་ཆོས་དང་ངེས་པའི་ཚིག་དང་སྤོབས་པ་དང་སྦྱར་ནས་བཤད་ན<ref name="palden-sherab" /><ref name="sangye-nyentrul" /> བསྟན་འཛིན་དོན་བཟང་གིས་ནི་ཤེས་རབ་རླབས་ཆེ་བ་དང་གསལ་བ་དང་མྱུར་བ་དང་ཟབ་པ་ཞེས་པའི་ཤེས་རབ་བཞི་དང་སྦྱར་ཏེ་གཞུང་ལུགས་མི་འདྲའོ།།<ref name="tenzin-dhonzang" />

== བསྡུས་དོན། ==
དེ་ལྟར་ན་སྒྲོལ་མའི་ཕྱག་འཚལ་ཉེར་གཅིག་གི་གཉིས་པའི་སྐུ་འདིར་མཚན་དང་སྐུའི་རྣམ་པ་དང་རྩ་ཚིག་གི་དོན་བཤད་པའི་ཐད་ནས་གཞུང་ལུགས་སོ་སོའི་ཁྱད་པར་ཆེར་ཡོད་ཀྱང<ref name="yama-sonam" /><ref name="gendun-drub" /> ཞལ་རས་སྟོན་ཀའི་ཟླ་བ་ལྟར་དཀར་ཞིང་འོད་ཟེར་སྐར་ཚོགས་ལས་ལྷག་པར་གསལ་བའི་སྒོ་ནས་ཤེས་རབ་ཀྱི་འོད་ཟེར་སྟོན་པའི་ལྷ་མོར་མཐའ་དག་གིས་ངོས་འཛིན་བྱེད་དོ།།<ref name="taranatha" /><ref name="palden-sherab" />

== དཔྱད་གཞིའི་ཡིག་ཆ། ==
* ཏཱ་ར་ནཱ་ཐ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།
* གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།
* བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།
* རྗེ་བཙུན་ཡ་མ་བསོད་ནམས། སྒྲོལ་མ་ཉེར་གཅིག་པའི་བསྟོད་འགྲེལ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།
* དངུལ་ཆུ་དྷརྨ་བྷ་དྲ། སྒྲོལ་མར་ཕྱག་འཚལ་ཉེར་གཅིག་གིས་བསྟོད་པའི་རྣམ་བཤད་ཡིད་འཕྲོག་ཨུཏྤལའི་ཆུན་པོ།
* རྒྱལ་བ་དགེ་འདུན་གྲུབ (ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་དང་པོ)། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཊཱིཀྐ་རིན་པོ་ཆེའི་ཕྲེང་བ།
* མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ།
* སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ། རྗེ་བཙུན་མ་སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་འགྲེལ་དང་དམིགས་རིམ་འཕགས་མའི་བྱིན་རླབས་གྲུ་ཆར།
