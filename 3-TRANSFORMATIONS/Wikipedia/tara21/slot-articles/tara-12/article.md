'''བཀྲ་ཤིས་དོན་གྲུབ་མ་'''ནི་ སྒྲོལ་མར་ཕྱག་འཚལ་ཉེར་གཅིག་གིས་བསྟོད་པའི་བཅུ་གཉིས་པའི་ཕྱག་འཚལ་ཡིན།<ref name="taranatha">ཏཱ་ར་ནཱ་ཐ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།</ref><ref name="gendun-gyatso">རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོ (ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་གཉིས་པ)། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་མའི་རྣམ་བཤད།</ref><ref name="konchok-thabkhe">དཀོན་མཆོག་ཐབས་མཁས (མིང་གཞན་བསྟན་པ་རྒྱ་མཚོ)། ཕྱག་འཚལ་ཉེར་གཅིག་མའི་ཊིཀྐ་འཕགས་མའི་ཞལ་ལུང་།</ref> རྩ་བའི་ཚིགས་བཅད་ལས་ "ཕྱག་འཚལ་ཟླ་བའི་དུམ་བུས་དབུ་རྒྱན། ། བརྒྱན་པ་ཐམས་ཅད་ཤིན་ཏུ་འབར་མ། ། རལ་པའི་ཁྲོད་ནས་འོད་དཔག་མེད་ལས། ། རྟག་པར་ཤིན་ཏུ་འོད་ནི་མཛད་མ།" ཞེས་གསུངས་པ་ལྟར<ref name="yama-sonam">རྗེ་བཙུན་ཡ་མ་བསོད་ནམས། སྒྲོལ་མ་ཉེར་གཅིག་པའི་བསྟོད་འགྲེལ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།</ref> ཟླ་བའི་དུམ་བུས་དབུ་ལ་བརྒྱན་ཞིང་རལ་པའི་ཁྲོད་ན་སངས་རྒྱས་འོད་དཔག་མེད་བཞུགས་པའི་ལྷ་མོ་ཡིན།།<ref name="dharmabhadra">དངུལ་ཆུ་དྷརྨ་བྷ་དྲ། སྒྲོལ་མར་ཕྱག་འཚལ་ཉེར་གཅིག་གིས་བསྟོད་པའི་རྣམ་བཤད་ཡིད་འཕྲོག་ཨུཏྤལའི་ཆུན་པོ།</ref><ref name="karma-maitri">ཀརྨ་མཻ་ཏྲི། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པའི་བསྡུས་འགྲེལ།</ref><ref name="palden-sherab">མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ།</ref>

== མཚན་གྱི་ངེས་ཚིག ==
འདིའི་མཚན་ལའང་གཞུང་ལུགས་སོ་སོས་མི་འདྲ་བར་གདགས་ཏེ་མཚན་གཅིག་ཏུ་མ་གྲུབ། རྗེ་བཙུན་ཡ་མ་བསོད་ནམས་ཀྱིས་རྗེ་བཙུན་མ་བཀྲིས་ཐམས་ཅད་སྦྱིན་མ་ཞེས་གདགས་ཤིང<ref name="yama-sonam" /> རང་ཉིད་ཀྱིས་ཀྱང་སློབ་དཔོན་གསུམ་གྱིས་ཅོ་ནེ་བཀྲིས་འབྱུང་གནས་མ་དང་ཉི་སྦས་ཀྱིས་བཀྲིས་ཐམས་ཅད་སྦྱིན་མ་དང་རྗེ་དགེ་འདུན་གྲུབ་ཀྱིས་བཀྲིས་སྣང་བའི་སྒྲོལ་མ་ཞེས་སོ་སོར་མཚན་བཏགས་པར་གསུངས་སོ།།<ref name="yama-sonam" />

སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་གིས་ནི་བཀྲ་ཤིས་འབྱུང་གནས་མ་ལ་བསྟོད་པ་ཞེས་གདགས་ཤིང<ref name="tenzin-dhonzang">སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།</ref> རྒྱལ་བ་དགེ་འདུན་གྲུབ་ཀྱི་འགྲེལ་པར་ཡང་མཚན་གཞན་ཞིག་བཀོད་དེ་བཤད་དོ།<ref name="gendun-drub">རྒྱལ་བ་དགེ་འདུན་གྲུབ (ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་དང་པོ)། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཊཱིཀྐ་རིན་པོ་ཆེའི་ཕྲེང་བ།</ref> མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་ཀྱིས་བཀྲ་ཤིས་དོན་བྱེད་སྒྲོལ་མ་ཞེས་གདགས་ཤིང<ref name="palden-sherab" /> སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ་དང་མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག་གཉིས་ཀྱིས་ནི་སྒྲོལ་མ་བཀྲ་ཤིས་དོན་གྲུབ་མ་ཞེས་པའི་མཚན་ཐ་དད་ཙམ་ཞིག་གིས་གདགས་སོ།།<ref name="sangye-nyentrul">སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ། རྗེ་བཙུན་མ་སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་འགྲེལ་དང་དམིགས་རིམ་འཕགས་མའི་བྱིན་རླབས་གྲུ་ཆར།</ref><ref name="tsultrim-namdak">མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག ། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།</ref>

སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་གིས་ཕྱག་འཚལ་ཞེས་པའི་ཚིག་གི་ངེས་ཚིག་ཀྱང་བཤད་དེ། སྣང་མཆེད་ཐོབ་གསུམ་གྱི་གཉིས་སྣང་ཕྲ་མོའི་བར་གྱི་ཕྱིན་ཅི་ལོག་གི་བློ་སྣ་མཐའ་དག་བདེ་བླག་ཏུ་འགགས་ཤིང་ཕྱིན་ཅི་མ་ལོག་པའི་བློ་སྣ་བདེ་བླག་ཏུ་སྐྱེ་བར་གསོལ་བ་འདེབས་པའི་དོན་དུ་འཆད་པ་ཞིག་ཡིན་ཏེ་གཞན་གྱིས་མ་བཤད།།<ref name="tenzin-dhonzang" />

== སྐུ་ཡི་རྣམ་པ། ==
དབུའི་རྒྱན་ཟླ་བའི་དུམ་བུ་སྟེ་ཚེས་གཅིག་གི་ཟླ་བས་དབུ་བརྒྱན་ཞིང་། དེ་དང་སྐུ་རྒྱན་གཞན་ཐམས་ཅད་ལས་སྡུག་བསྔལ་སེལ་བའི་འོད་ཟེར་དཀར་པོ་ཤིན་ཏུ་འབར་ཞིང་འཕྲོའོ།<ref name="dharmabhadra" /><ref name="karma-maitri" /><ref name="tenzin-dhonzang" /> འོན་ཏེ་རྗེ་བཙུན་ཡ་མ་བསོད་ནམས་ཀྱིས་ནི་ཚེས་གསུམ་གྱི་ཟླ་བར་བཤད་དེ་གཞན་དང་མི་མཐུན།<ref name="yama-sonam" /> རལ་པའི་ཁྲོད་ན་སངས་རྒྱས་འོད་དཔག་མེད་རིགས་བདག་གི་ཚུལ་དུ་བཞུགས་ཤིང་། དེ་ལས་དུས་རྟག་ཏུ་སེམས་ཅན་གྱི་དོན་དུ་འོད་ཟེར་འཕྲོའོ།།<ref name="yama-sonam" /><ref name="dharmabhadra" /><ref name="karma-maitri" />

ཇོ་ནང་ཏཱ་ར་ནཱ་ཐ་དང་མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་གཉིས་ཀྱིས་ནི་སངས་རྒྱས་འོད་དཔག་མེད་ལན་འགའ་དཀའ་ཐུབ་ཅན་གྱི་སྐུར་ཡང་སྟོན་པར་སོ་སོར་བཤད་དོ།<ref name="taranatha" /><ref name="palden-sherab" /> གསང་སྔགས་ཀྱི་བསྐྱེད་རིམ་གྱི་ཆ་ནས་ནི་མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་དང་སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ་གཉིས་ཀྱིས་སྐུ་མདོག་སེར་པོ། ཞལ་གཅིག་ཕྱག་གཉིས་ཏེ་གཡས་མཆོག་སྦྱིན་དང་གཡོན་གྱིས་དཀོན་མཆོག་གསུམ་མཚོན་པའི་ཨུཏྤལ་འཛིན་པའི་སྐུར་བཤད་དེ་ཨུཏྤལ་གྱི་སྟེང་ན་དཔལ་བེའུ་འོད་ཟེར་འཕྲོ་བ་ཞིག་ཡོད་པར་གཉིས་ཀས་མཐུན་པར་བཤད་དོ།<ref name="palden-sherab" /><ref name="sangye-nyentrul" /> འོན་ཀྱང་རྗེ་བཙུན་ཡ་མ་བསོད་ནམས་ཀྱིས་ནི་སྐུ་མདོག་གསེར་གྱི་མདོག་ཅན་ "ཞལ་གཅིག་ཕྱག་བརྒྱད་མ" ཞིག་ཏུ་བཤད་དེ<ref name="yama-sonam" /> རྩེ་གསུམ་དང་ལྕགས་ཀྱུ་སོགས་ཕྱག་མཚན་བརྒྱད་བསྣམས་པའི་སྐུར་འཆད་ཅིང་། གཞུང་འདིར་ཞལ་གཅིག་ཕྱག་གཉིས་ཀྱི་སྐུ་དང་ཞལ་གཅིག་ཕྱག་བརྒྱད་ཀྱི་སྐུ་གཉིས་ཀ་མ་བསྒྲེས་པར་གནས་སོ།།

== ཕྲིན་ལས་དང་ནུས་མཐུ། ==
འཁོར་འདིའི་ཕྲིན་ལས་སུ་འཇིག་རྟེན་གྱི་ཕྱུག་པོའམ་ལྷའི་ང་རྒྱལ་འཇོམས་ཏེ<ref name="taranatha" /><ref name="palden-sherab" /><ref name="sangye-nyentrul" /> མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་དང་མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག་གཉིས་ཀྱིས་ཀྱང་འོད་ཟེར་དེ་ལས་བདུད་རྩིའི་ཆར་བབས་ཏེ་རྩི་སྨན་དང་ལོ་ཏོག་རྒྱས་པར་བཤད་དོ།།<ref name="palden-sherab" /><ref name="tsultrim-namdak" />

ཟུར་མང་མཁན་པོ་པདྨ་རྣམ་རྒྱལ་གྱི་འགྲེལ་པར་ནི་འོད་ཟེར་དེས་ཚེ་དང་བསོད་ནམས་ཡོན་ཏན་མངའ་ཐང་རྟོགས་པ་སོགས་གདུལ་བྱའི་དོན་ཐམས་ཅད་རྒྱས་པར་བཤད་ཅིང<ref name="pema-namgyal">ལྡོམ་བུ་བ་པདྨ་རྣམ་པར་རྒྱལ་བ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་བདུད་རྩིའི་དགའ་ཚལ།</ref> སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་གིས་ནི་འོད་ཟེར་དེས་ལུས་ནད་དང་སེམས་ཀྱི་སྡུག་བསྔལ། སྡུག་བསྔལ་གསུམ། ཉེས་པ་དྲུག སྡུག་བསྔལ་བརྒྱད་བཅས་ཐམས་ཅད་དུད་ཁུའི་རྣམ་པར་ལུས་ལས་ཐོན་པར་བསྒོམ་ཞིང་སྔགས་ཀྱང་བཟླ་བར་བཤད་དེ་གཞན་དང་མི་འདྲ།།<ref name="tenzin-dhonzang" />

== གཞུང་ལུགས་སོ་སོའི་བཤད་པ། ==
ཇོ་ནང་ཏཱ་ར་ནཱ་ཐ་དང་མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་གཉིས་ཀྱིས་སྦས་དོན་གྱི་སྒོ་ནས་ཟླ་བའི་དུམ་བུའི་དབུ་རྒྱན་ནི་བྱང་ཆུབ་ཀྱི་སེམས་སྤྱི་བོར་བརྟན་པའི་མཚོན་བྱེད་དུ་བཤད་ཅིང<ref name="taranatha" /><ref name="palden-sherab" /> འོད་དཔག་མེད་ནི་ཐིག་ལེ་དམར་ཆའི་དངས་མའི་ངོ་བོར་བཤད་དེ་གཉིས་འཕོ་མེད་དུ་འཆིངས་ན་སྟོང་གཟུགས་ཕྱག་རྒྱ་ཆེན་པོའི་དཀྱིལ་འཁོར་མཐའ་ཡས་པར་འཆར་བར་སོ་སོར་བཤད་དོ།།<ref name="taranatha" /><ref name="palden-sherab" />

དཀོན་མཆོག་ཐབས་མཁས་ཀྱིས་ནི་གྲུབ་ཆེན་ཞིག་གི་ལུགས་སུ་ཟླ་བ་ཕྱེད་པའི་དབུ་རྒྱན་གྱིས་སྤྱི་བོའི་ཧཾ་ཡིག་མཚོན་ཞིང་། རིགས་བདག་འོད་དཔག་མེད་ནི་གྱེན་རྒྱུ་མེའི་རླུང་གི་ངོ་བོར་བཤད་དེ་ "གཏུམ་མོ་མཚོན་པའི་སྦས་བཤད་ཅིག་ཡོད་འདྲའོ" ཞེས་གསུངས་ཏེ<ref name="konchok-thabkhe" /> སྔ་མའི་ལུགས་གང་དང་ཡང་མི་མཐུན་ཞིང་གཞུང་འདིར་གཉིས་ཀ་མ་བསྒྲེས་པར་གནས་སོ།།

མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་ཁོ་ནས་མཐར་ཐུག་མཚན་མེད་རྫོགས་རིམ་གྱི་སྒོ་ནས་བཞི་པ་ཞིག་ཀྱང་བཤད་དེ། ཟླ་བའི་དུམ་བུའི་དབུ་རྒྱན་ནི་དབང་བཞི་པ་དོན་དམ་ཚིག་དབང་དང་། བརྒྱན་པ་ཐམས་ཅད་ཤིན་ཏུ་འབར་མ་ནི་ཉམས་སྣང་གོང་འཕེལ་གྱི་སྣང་བ་དང་། རལ་པའི་ཁྲོད་ན་འོད་དཔག་མེད་ནི་རིག་པ་ཚད་ལ་ཕེབས་པ་དང་། རྟག་པར་ཤིན་ཏུ་འོད་རབ་མཛད་མ་ནི་ཆོས་ཉིད་ཟད་སར་འཁྱོལ་བའི་སྣང་བར་སོ་སོར་སྦྱར་ཏེ་བཤད་དོ།།<ref name="palden-sherab" />

ཟུར་མང་མཁན་པོ་པདྨ་རྣམ་རྒྱལ་གྱི་འགྲེལ་པར་ཡང་སྦས་དོན་གྱི་ཐ་སྙད་གཞན་ཞིག་བཀོད་དེ། རལ་པའི་ཁྲོད་ན་འོད་དཔག་མེད་ནི་བུམ་དབང་དང་། ཟླ་བའི་དུམ་བུས་དབུ་རྒྱན་ནི་གསང་དབང་དུ་བཤད་དེ<ref name="pema-namgyal" /> དབང་བཞིའི་གདགས་གཞིའང་མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་ཀྱི་ལུགས་དང་མི་མཐུན་ཞིང་ཕྱག་འཚལ་གཞན་དག་གི་སྐབས་ནས་ཀྱང་བསྒྲེས་ཏེ་བཤད་པ་ཞིག་ཡིན།།

== བསྡུས་དོན། ==
དེ་ལྟར་ན་ཕྱག་འཚལ་ཉེར་གཅིག་གི་བཅུ་གཉིས་པའི་སྐུ་འདིར་མཚན་དང་སྐུའི་རྣམ་པ། སྦས་དོན་གྱི་བཤད་ཚུལ་བཅས་ལ་གཞུང་ལུགས་སོ་སོའི་ཁྱད་པར་མང་དུ་ཡོད་ཀྱང<ref name="yama-sonam" /><ref name="konchok-thabkhe" /> ཟླ་བའི་དུམ་བུས་དབུ་བརྒྱན་ཞིང་རལ་པའི་ཁྲོད་ན་འོད་དཔག་མེད་བཞུགས་པའི་ལྷ་མོ་ཡིན།།<ref name="dharmabhadra" /><ref name="tenzin-dhonzang" />

== དཔྱད་གཞིའི་ཡིག་ཆ། ==
* ཏཱ་ར་ནཱ་ཐ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།
* རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོ (ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་གཉིས་པ)། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་མའི་རྣམ་བཤད།
* དཀོན་མཆོག་ཐབས་མཁས (མིང་གཞན་བསྟན་པ་རྒྱ་མཚོ)། ཕྱག་འཚལ་ཉེར་གཅིག་མའི་ཊིཀྐ་འཕགས་མའི་ཞལ་ལུང་།
* རྗེ་བཙུན་ཡ་མ་བསོད་ནམས། སྒྲོལ་མ་ཉེར་གཅིག་པའི་བསྟོད་འགྲེལ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།
* དངུལ་ཆུ་དྷརྨ་བྷ་དྲ། སྒྲོལ་མར་ཕྱག་འཚལ་ཉེར་གཅིག་གིས་བསྟོད་པའི་རྣམ་བཤད་ཡིད་འཕྲོག་ཨུཏྤལའི་ཆུན་པོ།
