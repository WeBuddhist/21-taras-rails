'''སངས་རྒྱས་'''ཞེས་པ་ནི་རྗེ་བཙུན་སྒྲོལ་མ་ལ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་མང་པོའི་ནང་དུ་སྒྲུབ་ཉམས་ལེན་གྱི་མཐར་ཐུག་གི་འབྲས་བུར་བཤད་པའི་གོ་འཕང་ཡིན།།<ref name="drakpa-gyaltsen">རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།</ref><ref name="karma-maitri">ཀརྨ་མཻ་ཏྲི། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པའི་བསྡུས་འགྲེལ།</ref><ref name="palden-sherab">མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།</ref>

== ངེས་ཚིག ==
འགྲེལ་པ་མང་པོའི་ལུགས་ལ་སངས་རྒྱས་ཐམས་ཅད་ནི་ཡུམ་ཤེར་ཕྱིན་ལ་བརྟེན་ནས་འཁྲུངས་པ་ཡིན་པར་བཤད་དོ།<ref name="sungrab-tulku">འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།</ref><ref name="tenga-tulku">རྡོར་སློབ་བསྟན་དགའ་སྤྲུལ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཕན་ཡོན་དང་བཅས་པ་གསལ་བའི་མེ་ལོང་།</ref> ཟུར་མང་མཁན་པོ་པདྨ་རྣམ་རྒྱལ་གྱིས་ཀྱང་སངས་རྒྱས་པའི་རྒྱུར་ཕར་ཕྱིན་དྲུག་བཀོད་དེ་དེ་དག་ལ་སྤྱོད་ཡུལ་མཛད་པའི་ཕྱིར་རྗེ་བཙུན་མ་ཉིད་བྱང་ཆུབ་སེམས་མ་དང་རྒྱལ་བའི་སྲས་མོའི་ཚུལ་དུའང་འཇོག་པར་བཤད།<ref name="pema-namgyal">ལྡོམ་བུ་བ་པདྨ་རྣམ་པར་རྒྱལ་བ་། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་བདུད་རྩིའི་དགའ་ཚལ།</ref> རྒྱལ་བ་དགེ་འདུན་གྲུབ་ཀྱིས་རྗེ་བཙུན་མ་ཉིད་དུས་གསུམ་གྱི་སངས་རྒྱས་ཐམས་ཅད་ཀྱི་ཡུམ་དང་འཕྲིན་ལས་སུའང་ངོས་འཛིན་བྱེད་དོ།།<ref name="gendun-drub">རྒྱལ་བ་དགེ་འདུན་གྲུབ་(ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་དང་པོ)། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཊཱིཀྐ་རིན་པོ་ཆེའི་ཕྲེང་བ།</ref>

== མཚན་ཉིད། ==
སྒྲུབ་པའི་མཐར་ཐུག་གི་འབྲས་བུ་ཉིད་སངས་རྒྱས་ཀྱི་གོ་འཕང་ཡིན་པར་འགྲེལ་པ་མང་པོས་གསལ་བར་བཤད་དེ་ས་བཅུ་དང་ལམ་ལྔ་བགྲོད་ནས་ཐོབ་པར་ཐུབ་པ་ཡིན།།<ref name="drakpa-gyaltsen" /><ref name="karma-maitri" /><ref name="palden-sherab" />

== དབྱེ་བ། ==
སྐྱབས་ཡུལ་གྱི་སྐོར་དུ་སངས་རྒྱས་ནི་དཀོན་མཆོག་གསུམ་གྱི་དང་པོར་བཀོད་ལ་སྲས་རིགས་བཞིའི་ནང་གསེས་སུའང་བཤད་དེ་ཉན་ཐོས་དང་རང་སངས་རྒྱས་དང་བྱང་ཆུབ་སེམས་དཔའ་དང་ལྷན་དུ་སངས་རྒྱས་འཕགས་པའང་དེའི་ཡ་གྱལ་ཞིག་ཡིན་པར་བཤད་དོ།།<ref name="tsultrim-namdak">མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།</ref><ref name="palden-sherab" />

== གཞུང་ལུགས་སོ་སོའི་བཤད་པ། ==
'''མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་'''ནས་རྫོགས་ཆེན་ཨ་ཏི་ཡོ་གའི་ལྟར་ན་སངས་རྒྱས་ནི་མ་འོངས་པའི་གནས་སྐབས་ཙམ་མིན་པར་གདོད་མའི་ངོ་བོ་ཉིད་དུ་བཤད་དེ། "ངོ་བོ་སྟོང་པ་ཆོས་སྐུ། རང་བཞིན་གསལ་བ་ལོངས་སྐུ། ཐུགས་རྗེ་ཀུན་ཁྱབ་སྤྲུལ་སྟེ་སྐུ་གསུམ་ངོ་བོར་ཡེ་སངས་རྒྱས་པ་ཉིད་ཡིན་པའི་ཕྱིར" ཞེས་གསུངས།<ref name="palden-sherab" /> གནད་དེ་ཉིད་སྐྱེ་བ་གཅིག་གི་ནང་དུའང་འགྲུབ་པར་བཤད་དེ། "ནངས་རྟོགས་ན་ནངས་སངས་རྒྱས། ནུབ་རྟོགས་ན་ནུབ་སངས་རྒྱས" ཞེས་སོ།<ref name="palden-sherab" /> སངས་རྒྱས་ཞེས་པའི་མིང་མཁས་གྲུབ་ཕྱི་མའི་མཚན་གཞན་དུའང་སྦྱར་ཏེ་གུ་རུ་པདྨ་སཾ་བྷ་ཝ་ལ་སངས་རྒྱས་གཉིས་པ་ཞེས་མཚན་གསོལ་བ་དེ་ཡིན།།<ref name="palden-sherab" />

== བསྡུས་དོན། ==
འགྲེལ་པ་མང་པོའི་ནང་དུ་སངས་རྒྱས་ནི་སྒྲུབ་པའི་མཐར་ཐུག་གི་འབྲས་བུ་དང་ཡུམ་ཤེར་ཕྱིན་ལས་འཁྲུངས་པའི་གོ་འཕང་དང་སྐྱབས་ཡུལ་དཀོན་མཆོག་གསུམ་གྱི་དང་པོ་བཅས་སུ་བཤད་ལ་མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་ལྟ་བུའི་འགྲེལ་པ་ཁ་ཅིག་གིས་གདོད་མའི་ངོ་བོ་ཉིད་དུའང་བཤད་དོ།།<ref name="palden-sherab" />

== དཔྱད་གཞིའི་ཡིག་ཆ། ==
* རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།
* ཀརྨ་མཻ་ཏྲི། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པའི་བསྡུས་འགྲེལ།
* རྒྱལ་བ་དགེ་འདུན་གྲུབ་(ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་དང་པོ)། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཊཱིཀྐ་རིན་པོ་ཆེའི་ཕྲེང་བ།
* འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།
* རྡོར་སློབ་བསྟན་དགའ་སྤྲུལ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཕན་ཡོན་དང་བཅས་པ་གསལ་བའི་མེ་ལོང་།
* ལྡོམ་བུ་བ་པདྨ་རྣམ་པར་རྒྱལ་བ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་བདུད་རྩིའི་དགའ་ཚལ།
* མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།
* མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།
