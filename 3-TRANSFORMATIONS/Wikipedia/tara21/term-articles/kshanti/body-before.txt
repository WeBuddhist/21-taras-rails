'''བཟོད་པ་'''ནི་ཐེག་པ་ཆེན་པོའི་ཕར་ཕྱིན་དྲུག་གི་ཡ་གྱལ་ཞིག་སྟེ། རྗེ་བཙུན་སྒྲོལ་མར་ཕྱག་འཚལ་ཉེར་གཅིག་གིས་བསྟོད་པའི་གཞུང་གི་ཚིགས་བཅད་གསུམ་པ་ལས། "ཕྱག་འཚལ་གསེར་སྔོ་ཆུ་ནས་སྐྱེས་ཀྱི།། པདྨས་ཕྱག་ན་རྣམ་པར་བརྒྱན་མ༎ སྦྱིན་པ་བརྩོན་འགྲུས་དཀའ་ཐུབ་ཞི་བ།། བཟོད་པ་བསམ་གཏན་སྤྱོད་ཡུལ་ཉིད་མ།།" ཞེས་གསུངས་པ་ལྟར་རྗེ་བཙུན་མའི་སྤྱོད་ཡུལ་དུ་བསྟན་པའི་ཕར་ཕྱིན་དྲུག་གི་ནང་གསེས་ཤིག་ཡིན།།<ref name="sungrab-tulku">འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།</ref><ref name="tenzin-dhonzang">སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།</ref>

== ངེས་ཚིག ==
ངེས་ཚིག་གི་ཆ་ནས་བཟོད་པ་ཞེས་པ་ནི་བཟོད་པའི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ཉིད་ཡིན།།<ref name="drakpa-gyaltsen">རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།</ref>

== མཚན་ཉིད། ==
མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་ཀྱིས་ཚངས་པ་ཁྱད་པར་སེམས་ཀྱིས་ཞུས་པའི་ཐེག་པ་ཆེན་པོའི་མདོ་དྲངས་ནས་ཕར་ཕྱིན་དྲུག་སོ་སོའི་དོན་དམ་པའི་མཚན་ཉིད་བཤད་དེ། "མི་འཛིན་པ་ནི་སྦྱིན་པའོ། མི་བསྲུང་བ་ནི་ཚུལ་ཁྲིམས་སོ། མི་གནས་པ་ནི་བཟོད་པའོ། མི་བརྩོན་པ་ནི་བརྩོན་འགྲུས་སོ། མི་སེམས་པ་ནི་བསམ་གཏན་ནོ། མི་དམིགས་པ་ནི་ཤེས་རབ་བོ།" ཞེས་གསུངས་སོ།།<ref name="palden-sherab">མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།</ref>

== དབྱེ་བ། ==
བཟོད་པ་ལ་དབྱེ་ན་སྡུག་བསྔལ་དང་ལེན་གྱི་བཟོད་པ་དང་། གནོད་པ་ལ་ཇི་མི་སྙམ་པའི་བཟོད་པ་དང་། ཆོས་ལ་ངེས་ཐོབ་ཀྱི་བཟོད་པ་དང་གསུམ་དུ་ཕྱེ་བ་ཡོད།།<ref name="tenzin-dhonzang" />

ཕར་ཕྱིན་དྲུག་ལ་ཐབས་དང་སྟོབས་དང་སྨོན་ལམ་དང་ཡེ་ཤེས་བཞི་བསྣན་ནས་ཕར་ཕྱིན་བཅུར་བགྲང་བའི་ལུགས་ཀྱང་ཡོད་དེ། དེའི་ནང་བཟོད་པ་གསུམ་པར་བཞག་ནས་ས་བཅུའི་ཡོན་ཏན་དང་སྦྲེལ་ཏེ་བཤད།<ref name="palden-sherab" /><ref name="tenzin-dhonzang" /> རྒྱལ་བ་དགེ་འདུན་གྲུབ་ཀྱིས་རྗེ་བཙུན་མའི་ཐུགས་ཀའི་པདྨའི་ཕྱག་རྒྱ་ལ་ཕར་ཕྱིན་བཅུ་དག་པའི་རྟགས་སུ་བཤད།།<ref name="gendun-drub">རྒྱལ་བ་དགེ་འདུན་གྲུབ་(ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་དང་པོ)། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཊཱིཀྐ་རིན་པོ་ཆེའི་ཕྲེང་བ།</ref>

== ཁོང་ཁྲོའི་གཉེན་པོར་བཤད་པ། ==
བཟོད་པ་ནི་ཞེ་སྡང་དང་ཁོང་ཁྲོའི་གཉེན་པོར་བཤད་དེ། ཁོང་ཁྲོའི་སྐྱོན་གྱིས་མ་གོས་པའི་མཚན་ཉིད་ཅན་ཡིན་པར་ངེས།།<ref name="sungrab-tulku" /><ref name="tenga-tulku">རྡོར་སློབ་བསྟན་དགའ་སྤྲུལ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཕན་ཡོན་དང་བཅས་པ་གསལ་བའི་མེ་ལོང་།</ref><ref name="tenzin-dhonzang" />

== སྦས་དོན་གྱི་བཤད་པ། ==
གཞུང་འདིའི་སྦས་དོན་རྫོགས་རིམ་མཚན་བཅས་ཀྱི་སྐབས་སུ་བཟོད་པ་ནི་བདེ་སྡུག་ཐམས་ཅད་མཉམ་པར་སྙོམས་པའི་བཟོད་པ་ལ་གོ།།<ref name="palden-sherab" /><ref name="taranatha">ཏཱ་ར་ནཱ་ཐ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།</ref>

== གཞུང་ལུགས་སོ་སོའི་བཤད་པ། ==
'''རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོ་'''ནས་གོང་གི་ཕར་ཕྱིན་དྲུག་གི་ཚིག་དོན་ལ་ཡང་ན་ཞེས་པའི་བཤད་པ་གཞན་ཞིག་ཀྱང་བཀོད་དེ། "སྤངས་པ་དང་། བཟོད་པ་དང་། བསམ་གཏན་དང་དེ་ཁོ་ན་ཉིད་ཀྱི་སྤྱོད་ཡུལ་ཅན་གྱི་ཤེས་རབ་ཀྱི་བར་གྱི་ཕར་ཕྱིན་ཏེ། ཕར་ཕྱིན་དྲུག་ཡོངས་སུ་རྫོགས་པའི་བདག་ཉིད་ཅན་ཡིན་ནོ" ཞེས་གསུངས། འདི་ལྟར་ན་ཡང་ཕར་ཕྱིན་དྲུག་ཐམས་ཅད་ཚང་ཡང་། བཟོད་པ་དང་བསམ་གཏན་མ་གཏོགས་པའི་ཡ་གྱལ་གཞན་གཉིས་སུ་སྤངས་པ་དང་དེ་ཁོ་ན་ཉིད་ཀྱི་ཤེས་རབ་བཀོད་དེ། གཞན་འགྲེལ་པ་རྣམས་ཀྱིས་སྦྱིན་པ་དང་བརྩོན་འགྲུས་ཚུལ་ཁྲིམས་གསུམ་དུ་བཤད་པའི་ཚབ་ཏུ་བཀོད་པར་སྣང་ངོ་།<ref name="gendun-gyatso">རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོ (ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་གཉིས་པ)། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་མའི་རྣམ་བཤད།</ref> འགྲེལ་པ་གཞན་གང་གིས་ཀྱང་འདི་འདྲ་བའི་ཡང་བཤད་གཉིས་པ་མ་བཀོད་དོ།།

== མི་སྐྱེ་བའི་ཆོས་ལ་བཟོད་པ། ==
བཟོད་པ་ཞེས་པའི་སྒྲ་དེ་ཉིད་ཕར་ཕྱིན་གྱི་དོན་ལས་གཞན་དུའང་གཞུང་འདིའི་ལོ་རྒྱུས་ནང་དུ་འབྱུང་སྟེ། རྗེ་བཙུན་སྒྲོལ་མ་སྔོན་རྒྱལ་པོའི་བུ་མོར་གྱུར་པའི་དུས་སུ་རྒྱལ་པོའི་ཕོ་བྲང་དུ་འདོད་པའི་ཡོན་ཏན་ལྔ་ལ་ཐབས་མཁས་ཀྱིས་ལོངས་སྤྱོད་བཞིན་དུ་ཏིང་ངེ་འཛིན་བསྒོམས་པས་མི་སྐྱེ་བའི་ཆོས་ལ་བཟོད་པ་ཐོབ་ནས་འགྲོ་བ་ཐམས་ཅད་སྒྲོལ་བའི་ཏིང་ངེ་འཛིན་གྲུབ་པར་བཤད།<ref name="tenzin-dhonzang" /><ref name="sungrab-tulku" /><ref name="tsultrim-namdak">མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།</ref> འདི་ནི་ཕར་ཕྱིན་དྲུག་གི་ནང་གསེས་ཀྱི་བཟོད་པ་དེ་ཉིད་མིན་པར་ཐེག་ཆེན་ལམ་གྱི་གནས་སྐབས་ཤིག་ཏུ་གྲགས་པའི་ཆོས་ལ་བཟོད་པ་ཞེས་པའི་སྒྲུབ་པའི་གནས་སྐབས་ཐུན་མོང་མིན་པ་ཞིག་ཡིན།།

== བསྡུས་དོན། ==
བཟོད་པ་ནི་རྗེ་བཙུན་སྒྲོལ་མའི་སྤྱོད་ཡུལ་དུ་བསྟན་པའི་ཕར་ཕྱིན་དྲུག་གི་ཡ་གྱལ་ཞིག་ཡིན་ཞིང་། ཁོང་ཁྲོའི་གཉེན་པོར་ཡང་གྲགས།<ref name="sungrab-tulku" /> དབྱེ་ན་སྡུག་བསྔལ་དང་ལེན་དང་གནོད་པ་ལ་མི་སྙམ་པ་དང་ཆོས་ལ་ངེས་ཐོབ་ཅེས་པའི་གསུམ་དུའང་བཤད།<ref name="tenzin-dhonzang" /> དོན་དམ་པར་མི་གནས་པ་ཉིད་བཟོད་པ་ཡིན་པར་ཡང་བཤད་ཡོད།།<ref name="palden-sherab" />
