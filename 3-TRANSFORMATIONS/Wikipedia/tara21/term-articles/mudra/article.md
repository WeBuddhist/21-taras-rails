'''ཕྱག་རྒྱ་'''ནི་སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པའི་ཕྱག་འཚལ་དགུ་པའི་ཚིགས་བཅད་ལས། "ཕྱག་འཚལ་དཀོན་མཆོག་གསུམ་མཚོན་ཕྱག་རྒྱའི།། སོར་མོས་ཐུགས་ཀར་རྣམ་པར་བརྒྱན་མ།། མ་ལུས་ཕྱོགས་ཀྱི་འཁོར་ལོ་བརྒྱན་པའི། རང་གི་འོད་ཀྱི་ཚོགས་རྣམས་འཁྲུགས་མ།།" ཞེས་གསུངས་པའི་ལག་པའི་རྣམ་འགྱུར་ཞིག་ལ་བརྗོད་དོ།<ref name="sungrab-tulku">འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།</ref> འགྲེལ་པ་བཅུ་དྲུག་ཀའི་ནང་དུ་སྐབས་འདིའི་ཕྱག་རྒྱ་ཞེས་པ་དེ་དཀོན་མཆོག་གསུམ་མཚོན་པའི་ཕྱག་རྒྱ་ཡིན་པར་གསལ་བོར་ངོས་འཛིན་མཛད་དོ།།<ref name="yama-sonam">རྗེ་བཙུན་ཡ་མ་བསོད་ནམས། སྒྲོལ་མའི་འགྲེལ་བ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།</ref>

== ངེས་ཚིག ==
ཕྱག་རྒྱ་འདིའི་ལག་པའི་བཀོད་པ་ནི། "ཕྱག་གཡོན་པའི་མཐེབ་སྲིན་གཉིས་ཀྱིས་པདྨ་མའི་ཡུ་བ་ནས་བཟུང་ཤིང་། མཛུབ་མོ་གུང་མོ་མཐེའུ་ཆུང་གསུམ་གནམ་དུ་བསྒྲེང་བའི་ཕྱག་རྒྱ་ནི་དཀོན་མཆོག་གསུམ་མཚོན་པའི་ཕྱག་རྒྱ་སྟེ།" ཞེས་པ་ལྟར་རོ།<ref name="yama-sonam" /><ref name="drakpa-gyaltsen">རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།</ref><ref name="karma-maitri">ཀརྨ་མཻ་ཏྲི། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པའི་བསྡུས་འགྲེལ།</ref> འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུས་མཐེ་བོང་དང་སྲིན་ལག་གཉིས་ཀྱི་ཚབ་ཏུ་མཐེ་བོང་དང་གུང་མོ་གཉིས་ཀྱིས་ཨུཏྤལའི་ཡུ་བ་བཟུང་ཞིང་མཛུབ་མོ་དང་སྲིན་ལག་མཐེའུ་ཆུང་གསུམ་བསྒྲེང་བའི་ཁྱད་པར་ཞིག་གསུངས་སོ།།<ref name="sungrab-tulku" />

ཕྱག་གཡས་ཀྱི་མཆོག་སྦྱིན་གྱི་ཕྱག་རྒྱ་ནི་ཕྱག་མཐིལ་དུ་འཁོར་ལོ་རྩིབས་སྟོང་གི་རི་མོ་ཡོད་པ་ཞིག་སྟེ། དེའི་འོད་ཟེར་གྱིས་སེམས་ཅན་ལ་གནོད་པའི་འཇིགས་པ་བརྒྱད་དང་བཅུ་དྲུག་སོགས་སེལ་བར་བཤད་དོ།<ref name="sungrab-tulku" /> འཁོར་ལོའི་མཚན་རྟགས་འདིའི་སྐོར་གྱི་ཞིབ་འཇུག་ནི་[[འཁོར་ལོ་]]ཞེས་པའི་སྐབས་སུ་བཤད་དོ།།

== དབྱེ་བ། ==
ཕྱག་འཚལ་དགུ་པའི་ཕྱག་རྒྱ་འདི་ནི་ལག་པ་གཉིས་ཀའི་ཕྱག་རྒྱ་ཟུང་ཞིག་སྟེ། གཡོན་པ་དཀོན་མཆོག་གསུམ་མཚོན་པའི་ཕྱག་རྒྱ་དང་གཡས་པ་མཆོག་སྦྱིན་གྱི་ཕྱག་རྒྱའོ།<ref name="sungrab-tulku" /><ref name="yama-sonam" /> གཞུང་འདིའི་འགྲེལ་པ་ཁག་ཅིག་ཏུ་ཕྱག་རྒྱ་ཟུང་འདི་ཕྱག་འཚལ་དགུ་པ་ཙམ་དུ་མ་ཟད་ལྷ་ཚོགས་གཞན་གྱི་སྒྲུབ་ཐབས་ཀྱི་སྐབས་སུའང་བཀོལ་བ་སྟེ། མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་ཀྱིས་ཕྱག་འཚལ་ཉེར་གཅིག་གི་སྒོ་ནས་སྒྲོལ་མའི་སྤྲུལ་པ་ཉེར་གཅིག་སོ་སོའི་བསྐྱེད་རིམ་གྱི་དམིགས་པ་གསུངས་ཤིང་། དེ་རེ་རེར་ཡང་ཕྱག་གཡས་མཆོག་སྦྱིན་དང་གཡོན་དཀོན་མཆོག་གསུམ་མཚོན་གྱི་ཕྱག་རྒྱའི་སྒྲོམ་གཞི་གཅིག་མཚུངས་སྤྱད་དེ་ལྷ་སྐུ་སོ་སོའི་ཕྱག་མཚན་བྱེ་བྲག་པ་ཙམ་བརྗེས་པར་མཛད་དོ།<ref name="palden-sherab">མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།</ref> མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག་གིས་ཀྱང་རྩ་བའི་བསྟོད་པའི་ཕྱག་འཚལ་ཉེར་གཅིག་པོ་དེ་ཉིད་རང་གི་འགྲེལ་པའི་སྐབས་སུ་ལྷ་སྐུ་ཉེར་གཅིག་གི་སྒོ་ནས་བསྐྱར་དུ་བཤད་དེ། དེ་རེ་རེར་ཡང་ཕྱག་རྒྱ་ཟུང་མཚུངས་པ་སྤྱད་དོ།།<ref name="tsultrim-namdak">མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།</ref>

== དཀོན་མཆོག་གསུམ་དུ་མཚོན་པའི་རྒྱུ་མཚན། ==
དཀོན་མཆོག་གསུམ་མཚོན་པའི་རྒྱུ་མཚན་ལ་བཤད་ཚུལ་མི་འདྲ་བ་འགའ་ཞིག་ཡོད་དེ། རྗེ་བཙུན་ཡ་མ་བསོད་ནམས་ཀྱིས་དཀོན་མཆོག་གསུམ་མཚོན་པའི་ཕྱག་རྒྱ་དེ་རྒྱུ་སངས་རྒྱས་དཀོན་མཆོག་དང་ཆོས་དཀོན་མཆོག་གཉིས་ལས་བྱུང་ཞིང་བྱ་བ་དགེ་འདུན་རྗེས་སུ་སྐྱོང་བའི་དོན་སྟོན་པར་གསུངས་ལ།<ref name="yama-sonam" /> སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་གིས་ཕྱག་རྒྱ་མཛད་པའི་སོར་མོ་གསུམ་གྱིས་རང་གི་ཐུགས་ཀར་རྣམ་པར་བརྒྱན་པའི་སྒྲོལ་མ་ནི་དུས་གསུམ་གྱི་སངས་རྒྱས་ཐམས་ཅད་འདུས་པའི་བདག་ཉིད་ཡིན་པར་མཚོན་པར་བཤད་དོ།<ref name="tenzin-dhonzang">སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།</ref> དཀོན་མཆོག་ཐབས་མཁས་ཀྱིས་རྒྱལ་བ་དགེ་འདུན་གྲུབ་ཀྱི་སྒྲོལ་དཀར་བསྟོད་པ་དྲངས་ཏེ་ཕྱག་རྒྱ་དེ་ཉིད་དཀོན་མཆོག་མ་ལུས་པ་འདུས་པའི་ངོ་བོར་སྟོན་པར་ཡང་བཤད་དོ།།<ref name="konchok-thabkhe">དཀོན་མཆོག་ཐབས་མཁས་(མིང་གཞན་བསྟན་པ་རྒྱ་མཚོ)། ཕྱག་འཚལ་ཉེར་གཅིག་མའི་ཊིཀྐ་འཕགས་མའི་ཞལ་ལུང་།</ref>

== གཞུང་ལུགས་སོ་སོའི་བཤད་པ། ==
'''ཇོ་ནང་ཏཱ་ར་ནཱ་ཐ་'''ཡིས་ཕྱག་རྒྱ་འདིའི་སྐོར་ལ་གཞན་དང་མི་འདྲ་བའི་ལུགས་ཤིག་གསུངས་ཏེ། "དཀོན་མཆོག་གསུམ་མཚོན་པར་བྱེད་པ་ཨུཏྤ་ལའི་ཕྱག་རྒྱ་ནི་སྒྲོལ་མའི་དམ་ཚིག་གི་ཕྱག་རྒྱ་སྟེ།" ཞེས་ཕྱག་རྒྱ་འདི་ལྷ་མོ་ཉིད་ཀྱི་དམ་ཚིག་གི་ཕྱག་རྒྱར་ངོས་འཛིན་མཛད་དོ།<ref name="taranatha">ཏཱ་ར་ནཱ་ཐ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།</ref> ལག་པའི་བཀོད་པའང་གཞན་དང་མི་མཚུངས་པར་སྙིམས་པ་ཁ་སྦྱར་གྱི་གུང་མོ་སྦྱར་ཞིང་མཛུབ་མོས་བརྟེན་ནས་མཐེ་བོང་གཤིབས་ཏེ་རྩེ་བར་བཀོད་པ་ཐུགས་ཀར་གཏོང་བའི་ལག་པ་གཉིས་ཐལ་མོ་སྦྱར་བའི་ཕྱག་རྒྱར་བཤད་དོ།<ref name="taranatha" /> རིག་སྔགས་ཀྱི་ལྷས་བྱིན་གྱིས་བརླབས་པའི་དོན་སྔོན་བྱུང་བར་བཅོམ་ལྡན་འདས་མ་ཉིད་ཀྱང་ཕྱག་རྒྱ་དེ་འཆིང་བའི་སྐུར་སྟོན་པར་ཡང་བཤད་དོ།།<ref name="taranatha" />

'''རྗེ་བཙུན་ཡ་མ་བསོད་ནམས་'''ཀྱིས་ཚིགས་བཅད་འདིའི་འོད་ཟེར་གྱི་འབྱུང་ཁུངས་ལ་འགྲེལ་པ་རྣམས་ལ་བཞེད་པ་མི་འདྲ་བ་ཡོད་པར་བཀོད་དེ། འགྲེལ་པ་འགའ་ཞིག་གིས་ཕྱག་གཡས་པའི་མཐིལ་གྱི་འཁོར་ལོའི་འོད་ཟེར་ཡིན་པར་བཤད་ཅིང་། གཞན་དག་གིས་སྐུའི་འོད་ཟེར་ཡིན་པར་བཤད་པས་བཞེད་པ་མི་འདྲ་ཡང་། རང་ཉིད་ནི་སྐུའི་འོད་ཟེར་ཡིན་པའི་ཕྱོགས་སུ་བཞེད་དོ།།<ref name="yama-sonam" />

དེ་བཞིན་དུ་སྦས་དོན་གྱི་སྒོ་ནས་ཀྱང་'''ཇོ་ནང་ཏཱ་ར་ནཱ་ཐ་'''དང་'''མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་'''གཉིས་ཀས་ཕྱག་རྒྱ་འདིར་རྫོགས་རིམ་མཚན་བཅས་ཀྱི་སྦས་དོན་གཅིག་མཚུངས་སུ་བཀོད་ཡོད་དེ། དཀོན་མཆོག་གསུམ་མཚོན་པ་ནི་ཁུ་རྡུལ་རླུང་གསུམ་ལ་དགོངས་པ་ཡིན་ཞིང་། སོར་མོ་གསུམ་གྱིས་རྫས་གསུམ་པོ་དེ་ཉིད་ཐུགས་ཀའི་རྩ་འཁོར་གྱི་ལྟེ་བར་གཅིག་ཏུ་བཅིངས་པའི་ཚུལ་དུ་མཚོན་པར་གཉིས་ཀས་མཐུན་པར་བཤད་དོ།།<ref name="taranatha" /><ref name="palden-sherab" />

== ནུས་པ་དང་ཕྲིན་ལས། ==
སྔགས་དང་ཕྱག་རྒྱ་གཉིས་ཀ་བྱིན་གྱིས་བརླབས་པའི་གོ་ཆའི་ཚུལ་དུ་སྦྱར་ན་དགའ་བ་དང་བདེ་བའི་རྒྱུ་དེས་སྒྲུབ་པ་པོའི་སྒོ་གསུམ་ཀུན་ནས་བཅིངས་ཤིང་ནུས་སྟོབས་གཟི་བརྗིད་འབར་བ་དང་། ཕ་རོལ་གྱི་འཚེ་བ་དང་རྩོད་པ་སོགས་ཉིན་མཚན་གྱི་ལྟས་ངན་པ་ཐམས་ཅད་ཀྱང་སེལ་བར་བཤད་དོ།<ref name="taranatha" /><ref name="palden-sherab" /><ref name="tsultrim-namdak" /> གོ་ཆ་འདི་ཉིད་ལྷ་མོ་གཙུག་ཏོར་གདུགས་དཀར་མོའི་སྐབས་སུའང་མཚུངས་པར་བཤད་དོ།<ref name="palden-sherab" /> ཕྲིན་ལས་འདི་ཉིད་[[སྔགས་]]ཞེས་པའི་སྐབས་སུའང་ཞིབ་ཏུ་བཤད་ཡོད་པས་འདིར་མདོར་བསྡུས་སུ་བཀོད་པ་ཙམ་མོ།།

== བསྡུས་དོན། ==
འགྲེལ་པ་བཅུ་དྲུག་ཆར་དུ་ཕྱག་རྒྱའི་སྐོར་ལ་ཅུང་ཟད་རེ་གསུངས་ཡོད་ཅིང་། ཕྱག་འཚལ་དགུ་པའི་ཐོག་མའི་ཕྱག་རྒྱ་གཉིས་ཀ་དཀོན་མཆོག་གསུམ་མཚོན་པར་ངོས་འཛིན་མཛད་ཀྱང་། ལག་པའི་བཀོད་ཚུལ་དང་དཀོན་མཆོག་གསུམ་དུ་མཚོན་པའི་རྒྱུ་མཚན་དང་སྦས་དོན་གྱི་བཤད་ཚུལ་སོགས་ལ་འགྲེལ་པ་སོ་སོའི་བར་དུ་ཁྱད་པར་མང་དུ་མཆིས་སོ།།<ref name="yama-sonam" /><ref name="taranatha" />

== དཔྱད་གཞིའི་ཡིག་ཆ། ==
* རྗེ་བཙུན་ཡ་མ་བསོད་ནམས། སྒྲོལ་མའི་འགྲེལ་བ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།
* རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།
* ཀརྨ་མཻ་ཏྲི། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པའི་བསྡུས་འགྲེལ།
* དཀོན་མཆོག་ཐབས་མཁས་(མིང་གཞན་བསྟན་པ་རྒྱ་མཚོ)། ཕྱག་འཚལ་ཉེར་གཅིག་མའི་ཊིཀྐ་འཕགས་མའི་ཞལ་ལུང་།
* མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།
