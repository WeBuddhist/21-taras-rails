== གཞུང་ལུགས་སོ་སོའི་བཤད་པ། ==

'''དངུལ་ཆུ་དྷརྨ་བྷ་དྲ་'''ནས་ མིའམ་ཅི་ལ་མཚོན་བྱེད་དུ་ལྗོན་པ་དང་རྟ་མགོ་ཅན་གཉིས་ཀ་འདོན་ཏེ། "མིའམ་ཅི་ལྗོན་པ་རྟ་མགོ་ལ་སོགས་པ་རྣམས་ཀྱི་གཙུག་གིས་གུས་པས་ཞབས་པད་བསྟེན་མ།"ཞེས་གསུངས།<ref name="anon-utpala"/> དགེ་བཤེས་བློ་བཟང་ཟླ་བ་ཡིས་ཀྱང་མཐུན་པར་"མིའམ་ཅི་སྟེ་ལྗོན་པ་རྟ་མགོ་ལ་སོགས་པ"ཞེས་གསུངས།<ref name="lobsang-dawa"/> སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་ཡིས་ཀྱང་"མི་འམ་ཅི་ཡིས་ལྗོན་པའི་རྒྱལ་པོ་རྟ་མགོ་ལ་སོགས་པ་རྣམས"ཞེས་གོང་གཉིས་དང་མཐུན་པར་གསུངས།<ref name="tenzin-dhonzang"/>

'''རྒྱལ་བ་དགེ་འདུན་གྲུབ་'''ནས་ནི་རྟ་མགོའི་ཁྱད་ཆོས་མ་བཏོན་པར་"ལྷ་དང་མིའམ་ཅིའི་རྒྱལ་པོ་ལྗོན་པ་ཆེན་པོ་ལ་སོགས་པས་གཙུག་གིས་གུས་པས་བསྟེན་མ"ཞེས་གསུངས།<ref name="gendun-drub"/> རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན་ནས་ཀྱང་"ལྷ་ཚོགས་དེ་རྣམས་ཀྱི་དཔོན་ནམ་མི་འམ་ཅི་ཡི་རྒྱལ་པོ་ལྗོན་པ་ལ་སོགས་པས་ཞབས་ལ་མཆོད་པའོ།"ཞེས་མིང་མཐུན་པར་གསུངས་ཀྱང་རྟ་མགོའི་ཁྱད་ཆོས་མི་གསུང་།<ref name="drakpa-gyaltsen"/> འགྲེལ་པ་ལྔ་པོ་འདིས་མིང་གཅིག་མཚུངས་ལྗོན་པ་ཞེས་པའི་མིའམ་ཅིའི་རྒྱལ་པོའམ་མཚོན་བྱེད་འདོན་ཡང་། གཉིས་ཀྱིས་ནི་རྟ་མགོ་ཅན་ཞེས་པའི་ཁྱད་ཆོས་མི་སྣང་སྟེ། འགྲེལ་པ་ཁག་གིས་ལྗོན་པ་དང་རྟ་མགོ་ཅན་གཉིས་གཞིར་གཅིག་གི་ཆ་ཤས་སུ་བཞག་ཅིང་མི་འགལ་བར་བཤད།

འགྲེལ་པ་གཞན་བཅུ་གཅིག་གིས་ནི་མིའམ་ཅིའི་མིང་བྱེ་བྲག་ཏུ་མ་བཏོན་པར་ལྷ་དང་མིའམ་ཅི་གཉིས་ཀ་སྒྲོལ་མའི་ཞབས་ལ་གུས་པས་བརྟེན་ཅིང་བསྟེན་པར་མཐུན་པར་བཤད་དེ།<ref name="gendun-gyatso"/><ref name="karma-maitri"/><ref name="konchok-thabkhe"/><ref name="sangye-nyentrul"/><ref name="sungrab-tulku"/><ref name="taranatha"/><ref name="tsultrim-namdak"/><ref name="palden-sherab"/><ref name="anon-trinle-char"/><ref name="tenga-tulku"/><ref name="pema-namgyal"/> འགྲེལ་པ་གང་གིས་ཀྱང་གོང་གི་ལྗོན་པའམ་རྟ་མགོ་ཅན་ཞེས་པའི་མིང་དང་འགལ་བར་མི་གསུང་།

== འཇིག་རྟེན་བདུན་གྱི་ནང་གསེས། ==

'''ཏཱ་ར་ནཱ་ཐ་'''ནས་མཐུ་དང་ལྡན་པའི་འཇིག་རྟེན་བདུན་གྱི་ནང་གསེས་སུ་མིའམ་ཅི་བཞག་སྟེ། "ཀླུ་དང་ཡི་དྭགས་དང་ལྷ་མ་ཡིན་དང་། །མི་དང་རིག་པ་འཛིན་པ་དང་མིའམ་ཅི་དང་ལྷའི་འཇིག་རྟེན་ནོ།"ཞེས་གསུངས།<ref name="taranatha"/> སངས་རྒྱས་མཉན་སྤྲུལ་ནས་ཀྱང་མཐུན་པར་"ཀླུ། ཡི་དྭགས། ལྷ་མ་ཡིན།རིག་འཛིན། མི། མིའམ་ཅི། ལྷ་སྟེ་བདུན་པོ"ཞེས་གསུངས།<ref name="sangye-nyentrul"/> མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག་གིས་ཀྱང་"ཀླུ་དང་ ཡི་དྭགས་ལྷ་མ་ཡིན། མི་དང་རིག་པ་འཛིན་པ་མིའམ་ཅི་དང་ལྷའི་འཇིག་རྟེན་རྣམས"ཞེས་གོང་གཉིས་དང་མཐུན་པར་གསུངས།<ref name="tsultrim-namdak"/> འགྲེལ་པ་གསུམ་པོ་འདིས་འཇིག་རྟེན་བདུན་གྱི་ནང་གསེས་སུ་མིའམ་ཅི་གཏོགས་པར་མཐུན་པར་བཤད།

'''མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་'''ཀྱིས་ནི་མཁས་པ་གསུམ་གྱིས་འཇིག་རྟེན་བདུན་ལ་འཆད་ཚུལ་མི་འདྲ་བ་གསུམ་གསུངས་པར་འདྲེན་ཏེ། "འགྲོ་བ་རྒྱུད་ལྔ་དང་ཁམས་གོང་མ་གཟུགས་དང་གཟུགས་མེད་གཉིས་ཏེ་བདུན་ལ་འདོད།"ཅེས་གྲགས་པ་རྒྱལ་མཚན་གྱི་ལུགས་སུ་མིའམ་ཅི་མི་གསུང་ཞིང་། "ཀླུ་དང། ཡི་དྭགས་དང་། ལྷ་མིན་དང་། རིག་འཛིན་དང་། མི་དང་། མིའམ་ཅི་དང་། ལྷ་སྟེ་བདུན་ལ་བཞེད་དོ།"ཞེས་ཏཱ་ར་ནཱ་ཐའི་ལུགས་སུ་མིའམ་ཅི་གསུངས་ཤིང་། "འགྲོ་བ་རིགས་དྲུག་དང་། བར་དོར་བཞེད་དོ།"ཞེས་དགེ་འདུན་རྒྱ་མཚོའི་ལུགས་སུ་ཡང་མིའམ་ཅི་མི་གསུང་བར་བཤད་དེ་གཞུང་འདི་ཉིད་ཀྱིས་ལུགས་གང་ལའང་ཁས་ལེན་གསལ་པོ་མི་མཛད།<ref name="palden-sherab"/>

'''མཛད་པ་པོ་མ་གསལ་'''ལས་ཀྱང་བོད་དུ་དར་བའི་སྒྲོལ་མའི་དཔར་མའི་ཐོག་ཏུ་"འཇིག་རྟེན་བདུན"ཞེས་པའི་མིང་ཐོན་ཡང་། དེའི་དོན་ལ་བཤད་སྲོལ་མི་མཐུན་པ་མང་དུ་སྣང་བར་བཤད་ཅིང་། དེའི་ཁྲོད་ཡི་དྭགས་དང་ཀླུ་དང་མི་དང་རིག་པ་འཛིན་པ་དང་མིའམ་ཅི་དང་ལྷ་མ་ཡིན་དང་ལྷའི་འཇིག་རྟེན་ཞེས་པའང་གཅིག་ཡིན་ཡང་། "འཇིག་རྟེན་བདུན"ཞེས་པའི་མིང་འདི་ཉིད་ཡིག་ནོར་ཡིན་པར་མངོན་པར་བཤད་དོ།<ref name="anon-trinle-char"/>

== རྫོགས་རིམ་གྱི་བརྡ་དོན། ==

'''མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་'''ཀྱིས་ལྷ་དང་མིའམ་ཅི་ལ་རྫོགས་རིམ་མཚན་བཅས་ཀྱི་བརྡ་དོན་གསུངས་ཏེ། "ལྷའི་རྒྱལ་པོ་ནི་རྩ་དབུ་མ། ལྷ་དང་མིའམ་ཅི་ནི་རོ་རྐྱང་གཉིས།"ཞེས་གསུངས།<ref name="palden-sherab"/> རྫོགས་རིམ་མཚན་མེད་མཐར་ཐུག་གི་བརྡ་དོན་དུ་ནི་"ལྷ་དང་། མིའམ་ཅི་ཡིས་བསྟེན་མ་ནི། བསོད་ནམས་དང་། ཡེ་ཤེས་ཀྱི་ཚོགས་གཉིས་ཆེན་པོ་ངང་རྫོགས་སོ།"ཞེས་ཀྱང་གསུངས། འགྲེལ་པ་གཞན་གང་གིས་ཀྱང་མིའམ་ཅི་ལ་རྫོགས་རིམ་གྱི་བརྡ་དོན་སྟོན་མི་གསུང་།<ref name="palden-sherab"/>

== དབྱེ་བ། ==

སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་གིས་རྩ་བའི་བསྟོད་པའི་ཚིགས་བཅད་ལས་གཞན་པའི་གཞུང་ཞིག་(གདུགས་དཀར)ལས་དྲངས་ཏེ་གདོན་གཉེར་བརྒྱད་ཀྱི་ནང་གསེས་སུ་མིའམ་ཅིའི་གདོན་ཡང་གཏོགས་པར་བཤད། ཚིགས་བཅད་འདི་ཉིད་ནང་དུ་དྲི་ཟའི་གདོན་ཡང་ཐད་ཀར་གཅིག་མཚུངས་བཤད་ཡོད། འགྲེལ་པ་གཞན་གང་གིས་ཀྱང་མིའམ་ཅི་གདོན་གྱི་ནང་གསེས་སུ་མི་གསུང་།<ref name="tenzin-dhonzang"/>

== བསྡུས་དོན། ==

འགྲེལ་པ་བཅུ་དྲུག་ཀ་ཡིས་མིའམ་ཅི་ལྷ་དང་ལྷན་ཅིག་ཏུ་སྒྲོལ་མའི་ཞབས་ལ་བརྟེན་ཞིང་བསྟེན་པའི་སྲོག་ཆགས་སུ་བཤད།<ref name="anon-utpala"/> འགྲེལ་པ་ཁ་ཤས་ཀྱིས་མིའམ་ཅིའི་རྒྱལ་པོའམ་མཚོན་བྱེད་དུ་ལྗོན་པ་ཞེས་པའི་མིང་འདོན་ཞིང་། དེའི་ཁ་ཤས་ཀྱིས་རྟ་མགོ་ཅན་ཞེས་ཀྱང་མཚན་གཞག<ref name="tenzin-dhonzang"/> འཇིག་རྟེན་བདུན་གྱི་ནང་གསེས་སུ་མིའམ་ཅི་གཏོགས་མིན་ལའང་འགྲེལ་པ་ཁག་ཐ་དད་གནས་ཤིང་། "འཇིག་རྟེན་བདུན"ཞེས་པའི་མིང་ཉིད་ཡིག་ནོར་ཡིན་པར་བཤད་མཁན་ཡང་ཡོད།<ref name="anon-trinle-char"/> མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་གཅིག་པུས་ལྷ་དང་མིའམ་ཅི་ལ་རྫོགས་རིམ་གྱི་བརྡ་དོན་ཡང་གསུངས།<ref name="palden-sherab"/>

== དཔྱད་གཞིའི་ཡིག་ཆ། ==
* མཛད་པ་པོ་མ་གསལ། སྒྲོལ་མ་ཉེར་གཅིག་པའི་བསྟོད་འགྲེལ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།
* དངུལ་ཆུ་དྷརྨ་བྷ་དྲ། སྒྲོལ་མར་ཕྱག་འཚལ་ཉེར་གཅིག་གིས་བསྟོད་པའི་རྣམ་བཤད་ཡིད་འཕྲོག་ཨུཏྤལའི་ཆུན་པོ།
* རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།
* རྒྱལ་བ་དགེ་འདུན་གྲུབ། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཊཱིཀྐ་རིན་པོ་ཆེའི་ཕྲེང་བ།
* རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོ། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་མའི་རྣམ་བཤད།
* ཀརྨ་མཻ་ཏྲི། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པའི་བསྡུས་འགྲེལ།
* དཀོན་མཆོག་ཐབས་མཁས། ཕྱག་འཚལ་ཉེར་གཅིག་མའི་ཊིཀྐ་འཕགས་མའི་ཞལ་ལུང་།
* དགེ་བཤེས་བློ་བཟང་ཟླ་བ། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་མཆན་འགྲེལ།
