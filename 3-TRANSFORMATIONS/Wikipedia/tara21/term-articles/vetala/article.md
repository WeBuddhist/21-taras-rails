== དབྱེ་བ། ==
ཟུར་མང་མཁན་པོ་པདྨ་རྣམ་རྒྱལ་གྱིས་རོ་ལངས་ཀྱི་ནང་གསེས་སུ་ཤ་ལངས་དང་ཁྲག་ལངས་པགས་ལངས་སྨེ་ལངས་རྩ་ལངས་རུས་ལངས་བཅས་མིང་གྲངས་དྲུག་བཀོད་དེ་ནམ་གྲུ་ལ་སོགས་པའི་གདོན་ཆེན་བཅོ་བརྒྱད་དང་དུར་ཁྲོད་ཀྱི་འབྱུང་པོ་གནོད་སྦྱིན་གྱི་ཚོགས་དང་འབྲེལ་བར་བཤད་ཀྱང་། འགྲེལ་པ་གཞན་གང་གིས་ཀྱང་དབྱེ་བ་འདི་འདྲ་མི་གསུངས།།<ref name="pema-namgyal">ལྡོམ་བུ་བ་པདྨ་རྣམ་པར་རྒྱལ་བ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་བདུད་རྩིའི་དགའ་ཚལ།</ref>

== གཞུང་ལུགས་སོ་སོའི་བཤད་པ། ==
རོ་ལངས་ཀྱི་ངོ་བོ་ངེས་པའི་སྐོར་ལ་འགྲེལ་པ་སོ་སོས་ལྟ་བ་མི་འདྲ་བ་ལྔ་གསུངས། '''རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན་'''དང་'''རྒྱལ་བ་དགེ་འདུན་གྲུབ་'''དང་'''མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག་'''གསུམ་གྱིས་རོ་ལངས་ནི་དབང་ཕྱུག་ཆེན་པོས་གཙོ་བྱས་པའི་སྡེ་རིགས་ཤིག་ཏུ་བཤད།<ref name="drakpa-gyaltsen">རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།</ref><ref name="gendun-drub"/><ref name="tsultrim-namdak">མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།</ref> '''དངུལ་ཆུ་དྷརྨ་བྷ་དྲ་'''དང་'''དགེ་བཤེས་བློ་བཟང་ཟླ་བ་'''དང་'''འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ་'''གསུམ་གྱིས་སྲིན་པོའི་འཁོར་དུ་བཤད།<ref name="dharmabhadra"/><ref name="lobsang-dawa">དགེ་བཤེས་བློ་བཟང་ཟླ་བ། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་མཆན་འགྲེལ།</ref><ref name="sungrab-tulku">འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།</ref> '''ཀརྨ་མཻ་ཏྲི་'''དང་'''རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོ་'''གཉིས་ཀྱིས་གནས་ཡུལ་གྱིས་མཚོན་ཏེ་དུར་ཁྲོད་ན་གནས་པར་བཤད།།<ref name="karma-maitri">ཀརྨ་མཻ་ཏྲི། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པའི་བསྡུས་འགྲེལ།</ref><ref name="gendun-gyatso">རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོ (ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་གཉིས་པ)། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་མའི་རྣམ་བཤད།</ref>

'''མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་'''དང་'''སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ་'''གཉིས་ཀྱིས་རོ་ལངས་ནི་ལྷོ་ནུབ་ཕྱོགས་ཀྱི་དཀྱིལ་འཁོར་འཁོར་ལྷ་ལེགས་ལྡན་གྱིས་གཙོ་བྱས་པའི་སྲིན་པོའི་སྡེར་བཤད།<ref name="palden-sherab">མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།</ref><ref name="sangye-nyentrul">སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ། རྗེ་བཙུན་མ་སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་འགྲེལ་དང་དམིགས་རིམ་འཕགས་མའི་བྱིན་རླབས་གྲུ་ཆར།</ref> '''དཀོན་མཆོག་ཐབས་མཁས་'''ནི་གོང་གི་བཤད་སྟངས་ཐམས་ཅད་ལས་མི་འདྲ་བར་རོ་ལངས་ཞེས་པ་སྡེ་རིགས་རང་བཞིན་གྱིས་གྲུབ་པ་ཞིག་མིན་པར་སྲིན་པོས་ཞོན་པའི་རོ་ལ་བཏགས་པའི་མིང་ཙམ་དུ་བཤད་དེ། "རོ་ལངས་ཞོན་པའི་སྲིན་པོ"ཞེས་གསུངས།།<ref name="konchok-thabkhe">དཀོན་མཆོག་ཐབས་མཁས་(མིང་གཞན་བསྟན་པ་རྒྱ་མཚོ)། ཕྱག་འཚལ་ཉེར་གཅིག་མའི་ཊིཀྐ་འཕགས་མའི་ཞལ་ལུང་།</ref>

== ཕྲིན་ལས་དང་གནོད་པ། ==
རོ་ལངས་དང་འབྲེལ་བའི་གནོད་པ་ནི་སྤྱིར་བཏང་བ་ཞིག་མ་ཡིན་པར་རྦོད་གཏོང་ཞེས་པའི་ངན་སྔགས་ཀྱི་ལས་ཤིག་ཏུ་འགྲེལ་པ་མང་པོས་ངོས་འཛིན།།<ref name="dharmabhadra"/><ref name="palden-sherab"/><ref name="tenzin-dhonzang"/>

== ཕན་ཡོན། ==
ཟུར་མང་མཁན་པོ་པདྨ་རྣམ་རྒྱལ་གྱིས་སྒྲོལ་མའི་མདུན་དུ་རོ་ལངས་སོགས་འབྱུང་པོའི་ཚོགས་ཀྱང་སྐྲག་ཅིང་འདར་བཞིན་དུ་བསྟོད་པར་བཤད་ཅིང་། སྒྲོལ་མ་དེ་ལ་ཕྱག་འཚལ་ན་འབྱུང་པོ་དེ་དག་གི་འཇིགས་པ་ལས་ཚེ་འདི་དང་ཚེ་རབས་ཀུན་ཏུ་གྲོལ་བར་བཤད།།<ref name="pema-namgyal"/>

== རྫོགས་རིམ་གྱི་བརྡ་དོན། ==
མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་ཀྱིས་རྫོགས་རིམ་གྱི་སྐབས་སུ་རོ་ལངས་ལ་བརྡ་དོན་སོ་སོར་གསུངས་ཏེ། ས་བཅད་གཅིག་ཏུ་ཐིག་ལེ་དང་ས་བཅད་གཞན་ཞིག་ཏུ་ལས་སུ་བཤད་པས། འགྲེལ་པ་འདི་ཉིད་ཀྱི་ནང་དུ་ཡང་བརྡ་དོན་མི་འདྲ་བ་གཉིས་མངོན་ཞིང་། འགྲེལ་པ་གཞན་གང་གིས་ཀྱང་མཚུངས་པའི་བརྡ་དོན་མི་གསུངས།།<ref name="palden-sherab"/>

== བསྡུས་དོན། ==
འགྲེལ་པ་མང་པོས་རོ་ལངས་ནི་རྩ་བའི་ཚིགས་བཅད་ཀྱི་ནང་དུ་བཤད་ཀྱང་། དེའི་ངོ་བོ་ངེས་པར་ཅི་ཡིན་པའི་སྐོར་ལ་མཐུན་པའི་ལྟ་བ་གཅིག་མི་གསལ།།<ref name="yama-sonam"/>

== དཔྱད་གཞིའི་ཡིག་ཆ། ==
* རྗེ་བཙུན་ཡ་མ་བསོད་ནམས། སྒྲོལ་མ་ཉེར་གཅིག་པའི་བསྟོད་འགྲེལ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།
* དངུལ་ཆུ་དྷརྨ་བྷ་དྲ། སྒྲོལ་མར་ཕྱག་འཚལ་ཉེར་གཅིག་གིས་བསྟོད་པའི་རྣམ་བཤད་ཡིད་འཕྲོག་ཨུཏྤལའི་ཆུན་པོ།
* རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།
* རྒྱལ་བ་དགེ་འདུན་གྲུབ་(ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་དང་པོ)། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཊཱིཀྐ་རིན་པོ་ཆེའི་ཕྲེང་བ།
* རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོ (ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་གཉིས་པ)། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་མའི་རྣམ་བཤད།
* ཀརྨ་མཻ་ཏྲི། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པའི་བསྡུས་འགྲེལ།
* དཀོན་མཆོག་ཐབས་མཁས་(མིང་གཞན་བསྟན་པ་རྒྱ་མཚོ)། ཕྱག་འཚལ་ཉེར་གཅིག་མའི་ཊིཀྐ་འཕགས་མའི་ཞལ་ལུང་།
* དགེ་བཤེས་བློ་བཟང་ཟླ་བ། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་མཆན་འགྲེལ།
* མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།
* ལྡོམ་བུ་བ་པདྨ་རྣམ་པར་རྒྱལ་བ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་བདུད་རྩིའི་དགའ་ཚལ།
* སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ། རྗེ་བཙུན་མ་སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་འགྲེལ་དང་དམིགས་རིམ་འཕགས་མའི་བྱིན་རླབས་གྲུ་ཆར།
* འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།
* སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།
* མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།
