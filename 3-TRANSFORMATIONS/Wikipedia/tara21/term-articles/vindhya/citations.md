# Citations — vindhya (འབིགས་བྱེད)

**Revision note (Mode B, 2026-08-21).** This is a register-only rewrite of the v1 article at the
same path, produced under `wiki-article-from-claims-v2` Mode B (revision-in-place). No claim ID is
used here that was not already present in v1's reference map below. No `2-RAILS/Claims/` file or
raw tree-guided file was reopened; the only lookups performed were frontmatter-only reads of the
15 raw claims files' `author_in_use` key (Rule 17), confirming all 15 already carry a human-set
`author_in_use` value — no fallback to bare `author` was needed anywhere in this article.

Scope (unchanged from v1): this article covers *Vindhya* (འབིགས་བྱེད) as the third mountain named
alongside Meru and Mandara in the seventeenth homage of the *Twenty-One Praises to Tārā*, per
`2-RAILS/Claims/vindhya.md`. That consolidated page is itself framed as substantially a
cross-reference to `2-RAILS/Claims/meru.md` for the core naming/epithet material; this article
draws the same underlying claims directly from their raw tree-guided files (never from `meru.md`
itself), and gives independent full weight to the two facets `meru.md` does not carry: the
name-vs-verb grammatical divergence, and the generation-stage sādhana visualization.

## What changed from v1

- **Register**: the "Name and definition" section's ten-commentary who-said-what chain is now two
  wikivoice paragraphs (Rules 5, 8–9); the sādhana section's one long verbatim quotation is now a
  paraphrase attributed to Khenchen Palden Sherab, with Sangye Nyenpa Rinpoche and Khenpo Tsultrim
  Namdak's parallel visualizations folded in as a second sentence.
- **Quotation budget (Rule 6)**: 17 verbatim quotations → 2 (the root-verse quotation in the lead,
  `yama-sonam:c-3-17-3`, and the manuscript-variant quotation in the divergence section,
  `taranatha:c-17-7`). Both are unchanged, character-identical substrings of the quotations already
  marked PASS in v1's verification table (see *Verification* below) — no fresh `1-SOURCES/` lookup
  was performed for either.
- **Citation cap (Rule 7)**: no statement carries more than 3 `<ref>`s. See *Full attestation
  beyond in-article refs*.
- **Naming (Rule 17)**: v1's body never actually named a commentator with the wrong form — every
  in-prose name v1 used already matched that commentary's `author_in_use` (confirmed against the
  frontmatter reads in this revision). One stale label was removed: v1's name/definition section
  called `yama-sonam`'s commentary "མིང་མེད་པའི་འགྲེལ་པ་ཞིག་" ("an anonymous commentary") — an
  artifact of `yama-sonam`'s author being unidentified at v1's drafting time. `yama-sonam`'s claim
  quoted there (`c-3-17-8`) is dropped in this revision as redundant with the lead's root-verse
  quotation (`c-3-17-3`, same underlying tantra passage), so the stale label is removed by omission
  rather than corrected in place — see *Claims resolved but not incorporated*.
