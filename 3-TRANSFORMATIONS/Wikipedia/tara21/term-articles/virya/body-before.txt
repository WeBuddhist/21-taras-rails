'''བརྩོན་འགྲུས་'''ནི་ཕར་ཕྱིན་དྲུག་གི་ཡ་གྱལ་ཞིག་ཡིན་ཞིང་། "བརྩོན་འགྲུས་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའོ" ཞེས་ངེས་པར་བཤད་དོ།<ref name="drakpa-gyaltsen">རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།</ref> གཞུང་འདིའི་ཕྱག་འཚལ་གསུམ་པའི་ཚིགས་བཅད་ལས་སྦྱིན་པ་ཚུལ་ཁྲིམས་ཤེས་རབ་བཟོད་པ་བསམ་གཏན་བཅས་དང་ལྷན་ཅིག་ཏུ་ཕར་ཕྱིན་དྲུག་ཆར་རྗེ་བཙུན་སྒྲོལ་མའི་སྤྱོད་ཡུལ་དུ་གསུངས་ཤིང་། གནས་ཚུལ་འདི་ཉིད་འགྲེལ་པ་བཅུ་གཉིས་ཀྱིས་གསལ་བར་བཤད་དོ།།<ref name="tenzin-dhonzang">སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།</ref><ref name="tenga-tulku">རྡོར་སློབ་བསྟན་དགའ་སྤྲུལ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཕན་ཡོན་དང་བཅས་པ་གསལ་བའི་མེ་ལོང་།</ref><ref name="palden-sherab">མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།</ref>

== ངེས་ཚིག ==
འགྲེལ་པ་གཞན་གང་གིས་ཀྱང་ཚིག་འདི་ཉིད་ལ་ངེས་ཚིག་གཞན་མ་བཀོད་པར་ཕར་ཕྱིན་དྲུག་གི་ཡ་གྱལ་ཞིག་ཏུ་ངོས་འཛིན་བྱེད་པ་ཙམ་ཡིན།།<ref name="drakpa-gyaltsen" />

== མཚན་ཉིད། ==
འགྲེལ་པ་གསུམ་གྱིས་ནི་ཕར་ཕྱིན་དྲུག་པོ་འདི་ཉིད་རྗེ་བཙུན་སྒྲོལ་མ་ཉིད་ཀྱི་འབྱུང་རྒྱུར་ངོས་འཛིན་བྱེད་དེ། ལྷ་མོ་ཕར་ཕྱིན་དྲུག་མངོན་སུམ་གྱིས་སྤྱོད་ཡུལ་དུ་བྱས་པ་ལས་བྱུང་ཞིང་བརྩོན་འགྲུས་ཀྱང་ལེ་ལོའི་སྐྱོན་གྱིས་མ་གོས་པའི་ཆ་ནས་ཕར་ཕྱིན་དྲུག་གི་རྒྱུར་གྱུར་པར་བཤད་ལ།<ref name="tenzin-dhonzang" /><ref name="tenga-tulku" /> ལྷ་མོས་ཕར་ཕྱིན་དྲུག་གི་སྤྱོད་པ་དང་བཅས་ཏེ་དབང་བཅུའི་ཡོན་ཏན་མངོན་དུ་བྱས་པར་ཡང་གསུངས།།<ref name="palden-sherab" />

== དབྱེ་བ། ==
སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་ནི་བརྩོན་འགྲུས་ལ་དབྱེ་བ་ལྔར་འབྱེད་དེ། གོ་ཆའི་བརྩོན་འགྲུས་དང་། སྦྱོར་བའི་བརྩོན་འགྲུས་དང་། མི་འགོངས་པའི་བརྩོན་འགྲུས་དང་། མི་ལྡོག་པའི་བརྩོན་འགྲུས་དང་། ཆོག་པར་མི་འཛིན་པའི་བརྩོན་འགྲུས་ཏེ་ལྔར་བཞེད།<ref name="tenzin-dhonzang" /> དཀོན་མཆོག་ཐབས་མཁས་ནི་ཕར་ཕྱིན་དྲུག་གི་གོ་རིམ་ཡོངས་གྲགས་ལས་གཞུང་འདིར་བརྩོན་འགྲུས་སྔོན་དུ་བཀོད་པའི་རྒྱུ་མཚན་བརྩོན་འགྲུས་བསོད་ནམས་ཀྱི་ཚོགས་དང་ཡེ་ཤེས་ཀྱི་ཚོགས་གཉིས་ཀ་ལ་ཐུན་མོང་དུ་གཏོགས་པའི་ཕྱིར་ཡིན་པར་བཤད་དོ།།<ref name="konchok-thabkhe">དཀོན་མཆོག་ཐབས་མཁས་(མིང་གཞན་བསྟན་པ་རྒྱ་མཚོ)། ཕྱག་འཚལ་ཉེར་གཅིག་མའི་ཊིཀྐ་འཕགས་མའི་ཞལ་ལུང་།</ref>

== ལེ་ལོའི་གཉེན་པོ། ==
འགྲེལ་པ་གཉིས་ཀྱིས་བརྩོན་འགྲུས་ལ་ལེ་ལོའི་གཉེན་པོར་ངོས་འཛིན་བྱེད་དེ། འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུས་ཕར་ཕྱིན་དྲུག་སོ་སོའི་གཉེན་པོའི་སྐབས་སུ་བརྩོན་འགྲུས་ཉིད་ལེ་ལོའི་གཉེན་པོར་བཤད་ཅིང་།<ref name="sungrab-tulku">འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།</ref> སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་གིས་ཕར་ཕྱིན་དྲུག་གི་ནང་གི་དགྲ་བོ་བཤད་པའི་སྐབས་སུ་བརྩོན་འགྲུས་ཀྱི་དགྲར་ལེ་ལོའི་རྣམ་པ་བཞི་བཀོད་དོ།<ref name="tenzin-dhonzang" /> འོན་ཀྱང་གཞུང་གཞན་ཞིག་དྲངས་ནས་རྒྱལ་བའི་སྲས་རྣམས་ཀྱིས་ལེ་ལོ་ཀུན་སེལ་བའི་བརྩོན་འགྲུས་ཆེན་པོ་ལ་བརྩམས་པར་ཡང་གསུངས།།<ref name="tenzin-dhonzang" />

== ཕར་ཕྱིན་བཅུའི་གྲངས་སུ་གཏོགས་པ། ==
འགྲེལ་པ་གཉིས་ཀྱིས་ཕར་ཕྱིན་དྲུག་མ་ཟད་ཕར་ཕྱིན་བཅུའི་གྲངས་སུ་ཡང་བརྩོན་འགྲུས་བཀོད་དེ། ས་བཅུ་དང་འབྲེལ་བའི་སྦྱིན་པ་ཚུལ་ཁྲིམས་བཟོད་པ་བརྩོན་འགྲུས་བསམ་གཏན་ཤེས་རབ་ཐབས་མཁས་སྨོན་ལམ་སྟོབས་ཡེ་ཤེས་ཀྱི་ཕར་ཕྱིན་བཅུའི་ནང་དུ་བརྩོན་འགྲུས་ནི་བཞི་པར་གནས་པར་གཞུང་མཐུན་པར་བཤད་དོ།།<ref name="tenzin-dhonzang" /><ref name="palden-sherab" />

== རྒྱུད་སྡེའི་ཉམས་ལེན། ==
མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་ཁོ་ནས་བརྩོན་འགྲུས་ཉིད་རྫོགས་རིམ་གྱི་ཉམས་ལེན་གྱི་སྐབས་སུ་བཀོད་དེ། རྩ་མདུད་ཉེར་གཅིག་གྲོལ་བའི་སྐབས་སུ་བྱང་ཆུབ་ཀྱི་སེམས་དང་བརྩོན་འགྲུས་ཀྱིས་གཞུང་བསྲང་བར་བཤད་ལ།<ref name="palden-sherab" /> ཁྲེགས་ཆོད་དང་ཐོད་རྒལ་གྱི་ལམ་གཉིས་ཀྱི་སྐབས་སུ་ཡང་ཤེས་རབ་དང་བརྩོན་འགྲུས་གཉིས་ཟབ་མོའི་ལམ་གྱི་སྲོག་ཤིང་ལྟ་བུར་བཀོད་དོ།།<ref name="palden-sherab" />

== གཞུང་ལུགས་སོ་སོའི་བཤད་པ། ==
'''རྒྱལ་བ་དགེ་འདུན་གྲུབ་'''ནི་ཕྱག་འཚལ་གསུམ་པའི་ཕྱག་རྒྱའི་བརྡ་ཐད་ཀར་གཞུང་གཞན་དུ་བཤད་དེ། "ཕ་རོལ་ཏུ་ཕྱིན་པ་བཅུ་དག་པའི་རྟགས་སོ" ཞེས་གསུངས་ནས་སྦྱིན་པ་བརྩོན་འགྲུས་ཚུལ་ཁྲིམས་བཟོད་པ་བསམ་གཏན་ཤེས་རབ་སྟེ་ཚིག་དྲུག་པོ་གཞན་དང་མཚུངས་པ་བཀོད་ཀྱང་། གྲངས་ཀ་བཅུར་བཀོད་པའི་རྒྱུ་མཚན་གསལ་བར་མ་བཤད་དོ།།<ref name="gendun-drub">རྒྱལ་བ་དགེ་འདུན་གྲུབ་(ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་དང་པོ)། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཊཱིཀྐ་རིན་པོ་ཆེའི་ཕྲེང་བ།</ref>

'''མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་'''ནས་བརྩོན་འགྲུས་ཉིད་སྒྲུབ་པ་པོའི་རྒྱུའི་ཆ་ཤས་སུ་བཀོད་དེ། སྲོད་དང་ཐོ་རངས་ལའང་མི་ཉལ་བར་མལ་སྟན་ལས་ལྡང་བར་བྱས་པའི་ཐད་ཀར་བརྩོན་འགྲུས་ཀྱི་ཁྱད་པར་དུ་བཤད།<ref name="palden-sherab" /> འདུལ་བ་ལས་དྲངས་ནས་ཀྱང་དད་པ་བརྩོན་འགྲུས་དྲན་པ་ཏིང་ངེ་འཛིན་ཤེས་རབ་ཆེན་པོ་ཡོད་ན་རྗེ་བཙུན་སྒྲོལ་མའི་ཐུགས་རྗེའི་བྱིན་རླབས་ཕྱོགས་ལྷུང་མེད་པར་འབྱུང་བར་བཤད།<ref name="palden-sherab" /> མཁན་ཆེན་དེས་ཀྱང་བརྩོན་འགྲུས་ཀྱི་དོན་དམ་པའི་ངེས་ཚིག་ཐད་ཀར་ཚངས་པ་ཁྱད་པར་སེམས་ཀྱིས་ཞུས་པའི་མདོ་དྲངས་ནས་ཕར་ཕྱིན་དྲུག་སོ་སོའི་དོན་དམ་དགག་སྒྲུབ་ཀྱི་ངེས་ཚིག་བཀོད་དེ། བརྩོན་འགྲུས་ཉིད་མི་བརྩོན་པའི་དོན་དུ་བཤད་དོ།།<ref name="palden-sherab" />

'''མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག་'''ནས་བརྩོན་འགྲུས་ཉིད་བསྟན་པ་འཛིན་པའི་རྒྱུ་གཞན་གཉིས་ཀྱི་གྲོགས་སུ་བཀོད་དེ། སི་ཏུ་པདྨ་ཉིན་བྱེད་ཀྱི་གསུང་དྲངས་ནས་ཐོས་དོན་སྒོམ་པས་རང་རྒྱུད་དུལ་བ་དང་དེའི་གྲོགས་སུ་བརྩོན་འགྲུས་རྩོམ་པ་སྟེ་ཆོས་གསུམ་སངས་རྒྱས་ཀྱི་བསྟན་པ་འཛིན་པར་མེད་ཐབས་མེད་པར་བཤད་དོ།།<ref name="tsultrim-namdak">མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།</ref>

'''ཇོ་ནང་ཏཱ་ར་ནཱ་ཐ་'''ནས་བརྩོན་འགྲུས་ལ་སྦས་དོན་གྱི་བཤད་པ་ཐད་ཀར་བཀོད་དེ། གཞུང་གི་སྦས་དོན་བཤད་པའི་སྐབས་སུ་བརྩོན་འགྲུས་ཀྱང་ནང་དོན་གྱི་ངོ་བོར་བཤད་ཅིང་། གང་ཞིག་ལ་བརྟེན་ནས་མི་མངའ་བར་གསུངས་པ་གསལ་བར་མ་བཀོད་དོ།།<ref name="taranatha">ཏཱ་ར་ནཱ་ཐ་། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།</ref>

== བསྡུས་དོན། ==
འགྲེལ་པ་མང་པོའི་ནང་དུ་བརྩོན་འགྲུས་ནི་ཕར་ཕྱིན་དྲུག་གི་ཡ་གྱལ་ཞིག་ཏུ་གསལ་བར་ངོས་འཛིན་བྱེད་ཅིང་། གཞུང་འདིའི་ཕྱག་འཚལ་གསུམ་པའི་ཚིགས་བཅད་ལས་རྗེ་བཙུན་སྒྲོལ་མའི་སྤྱོད་ཡུལ་ལམ་འབྱུང་རྒྱུར་ཡང་ངོས་འཛིན་བྱེད་དོ།<ref name="tenzin-dhonzang" /> ལེ་ལོའི་གཉེན་པོར་ངོས་འཛིན་བྱེད་པ་དང་། ཕར་ཕྱིན་བཅུའི་གྲངས་སུ་བཞི་པར་གནས་པ། དབྱེ་བ་ལྔར་འབྱེད་པ་བཅས་ཀྱང་བཤད་ལ།<ref name="sungrab-tulku" /><ref name="palden-sherab" /> འགྲེལ་པ་འགའ་ཞིག་གིས་རྒྱུད་སྡེའི་ཉམས་ལེན་གྱི་སྐབས་དང་། དོན་དམ་པའི་ངེས་ཚིག། དེ་བཞིན་སྦས་དོན་གྱི་སྒོ་ནས་ཀྱང་བཤད་དོ།།<ref name="palden-sherab" /><ref name="taranatha" />
