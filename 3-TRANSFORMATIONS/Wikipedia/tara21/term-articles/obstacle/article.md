'''བགེགས་'''ནི་འགྲོ་བ་སེམས་ཅན་གྱི་དགེ་སྦྱོར་དང་བདེ་སྐྱིད་ལ་བར་ཆད་སྐྱེལ་བའི་མི་མཐུན་ཕྱོགས་ཀྱི་སེམས་ཅན་གྱི་རིགས་ཤིག་ལ་བརྗོད་པ་ཡིན།<ref name="taranatha">ཏཱ་ར་ནཱ་ཐ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།</ref> ཕྱག་འཚལ་ཉེར་གཅིག་གི་འགྲེལ་པ་འགའ་ཞིག་གིས་འབྱུང་པོ་ཞེས་པའི་མིང་ལ་བགེགས་ཀྱི་རིགས་སུ་ངོས་འཛིན་བྱེད་ཅིང༌།<ref name="taranatha" /><ref name="palden-sherab">མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།</ref> ཡང་ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཚིགས་བཅད་བཅུ་བཞི་པར་བགེགས་ཀྱི་རིགས་སོ་སོར་ངོས་འཛིན་བྱེད་མཁན་ཡང་ཡོད་ཀྱང་བགེགས་ཀྱི་མིང་ཐད་ཀར་མི་བཀོད་པར་ཀླུ་སྲིན་སོགས་ཀྱི་མིང་གིས་མཚོན་པའི་འགྲེལ་པ་ཡང་མང་དུ་ཡོད།།<ref name="drakpa-gyaltsen">རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།</ref>

== ངེས་ཚིག ==
ཕྱག་འཚལ་ཉེར་གཅིག་གི་འགྲེལ་པ་མང་པོའི་ནང་དུ་ཕྱག་འཚལ་ཚིགས་བཅད་ཤིག་གི་ནང་གི་འབྱུང་པོ་ཞེས་པའི་སྡེ་ཚན་ལ་ཚོགས་ཀྱི་བདག་པོ་སོགས་བགེགས་དང་ལོག་འདྲེན་བྱེད་མཁན་གྱི་རིགས་སུ་ངོས་འཛིན་བྱེད་དོ།<ref name="taranatha" /><ref name="palden-sherab" /><ref name="tsultrim-namdak">མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།</ref> འོན་ཀྱང་རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན་གྱིས་ཚིགས་བཅད་མཚུངས་པའི་འབྱུང་པོའི་གནོད་བྱེད་ལ་བགེགས་ཞེས་པའི་མིང་ཐད་ཀར་མི་བཀོད་པར་ལྷ་མིང་ཞིག་གིས་མཚོན།།<ref name="drakpa-gyaltsen" />

== དབྱེ་བ། ==
ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཚིགས་བཅད་བཅུ་བཞི་པར་བགེགས་ཀྱི་རིགས་ལ་དམ་སྲི་དང་འགོང་པོ་སྤུན་དགུ་དང་སྡེ་བརྒྱད་ཅེས་གསུམ་དུ་དབྱེ་ནས་"བཅུ་བཞི་པ་དམ་སྲི་བགེགས་རིགས་འགོང་པོ་སྤུན་དགུ་དང་སྡེ་བརྒྱད་གནོད་པ་འཇོམས་པའི་འཕགས་མ་སྒྲོལ་མ་ཁྲོ་གཉེར་ཅན་མ" ཞེས་མཚན་བཏགས།<ref name="palden-sherab" /><ref name="sangye-nyentrul">སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ། རྗེ་བཙུན་མ་སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་འགྲེལ་དང་དམིགས་རིམ་འཕགས་མའི་བྱིན་རླབས་གྲུ་ཆར།</ref> འོན་ཀྱང་འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུས་ཚིགས་བཅད་དེ་ཉིད་ལ་དམ་སྲི་ཞེས་པའི་མིང་བཀོད་ཀྱང་བགེགས་ཞེས་པའི་མིང་མི་སྦྱོར།།<ref name="sungrab-tulku">འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།</ref>

== གཞུང་ལུགས་སོ་སོའི་བཤད་པ ==
ཚིགས་བཅད་བཅུ་བཞི་པའི་གནོད་པ་བྱེད་མཁན་གྱི་མིང་ཐད་ལ་འགྲེལ་པ་རྣམས་མི་མཐུན་ཏེ། '''རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན་'''དང་'''ཇོ་ནང་ཏཱ་ར་ནཱ་ཐ་'''གཉིས་ཀས་བགེགས་ཞེས་པའི་མིང་ཐད་ཀར་མི་བཀོད་པར་ས་འོག་རིམ་པ་བདུན་ན་གནས་པའི་ཀླུ་དང་ལྷ་མིན་དང་སྲིན་པོ་དང་ཡི་དྭགས་གདུག་པ་ཅན་རྣམས་དུམ་བུར་འཐོར་ཞིང་འགེམས་པར་མཛད་པའི་མིང་གིས་མཚོན།<ref name="drakpa-gyaltsen" /><ref name="taranatha" /> ཟུར་མང་མཁན་པོ་པདྨ་རྣམ་རྒྱལ་དང་མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག་གཉིས་ཀྱང་ཚིགས་བཅད་མཚུངས་པར་མིང་དེ་དག་གིས་མཚོན་པ་ལ་མཐུན་པར་གནས།<ref name="pema-namgyal">ལྡོམ་བུ་བ་པདྨ་རྣམ་པར་རྒྱལ་བ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་བདུད་རྩིའི་དགའ་ཚལ།</ref><ref name="tsultrim-namdak" /> འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུས་ཀྱང་དམ་སྲི་ཞེས་པའི་མིང་བཀོད་ཀྱང་བགེགས་ཞེས་པའི་མིང་མི་སྦྱོར་བས་ཕྱོགས་མཚུངས་སུ་གནས།།<ref name="sungrab-tulku" />
འོན་ཀྱང་'''མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་'''དང་'''སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ་'''གཉིས་ཀས་ཚིགས་བཅད་དེ་ཉིད་ཀྱི་མཚན་ཐད་ཀར་ལ་དམ་སྲི་བགེགས་རིགས་ཞེས་བགེགས་ཞེས་པའི་མིང་ཐད་ཀར་སྦྱོར།།<ref name="palden-sherab" /><ref name="sangye-nyentrul" />

== ཕྲིན་ལས་དང་ནུས་མཐུ། ==
སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་གིས་གླུད་ཀྱི་ལག་ལེན་ཞིག་བཤད་དེ། རང་གི་ཉེས་ལྟུང་སྡིག་སྒྲིབ་བླ་མའི་སྐུ་གླུད་དང་སེམས་ཅན་ཐམས་ཅད་ཀྱི་ཚེ་སྲོག་གི་གླུད་དུ་བཏང་ནས་"རང་ལ་གནོད་ཅིང་འཚེ་བའི་གདོན་བགེགས་ཀྱི་རིགས་ཡོད་ན། གདོན་བགེགས་ཐམས་ཅད་ཀྱང་དེས་ཚིམས་པ" ཡིན་པར་བཤད།<ref name="tenzin-dhonzang">སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།</ref> དེ་ཉིད་ཀྱིས་ལྷ་མོ་འདིའི་འཕྲིན་ལས་ཀྱི་གཙོ་བོར་སྐབས་མང་པོར་བགེགས་ཞི་བར་མཛད་པའི་ཚིག་གིས་བརྗོད་ཀྱང་ཚིགས་བཅད་སོ་སོར་གནོད་པ་སྤྱོད་མཁན་གྱི་མིང་གསལ་བར་མི་བཀོད།།<ref name="tenzin-dhonzang" />

== བསྡུས་དོན། ==
འགྲེལ་པ་མང་པོའི་ནང་དུ་བགེགས་ཞེས་པ་གདོན་དང་བདུད་སོགས་དང་མཉམ་དུ་སྤྱིར་བཏང་གི་མི་མཐུན་ཕྱོགས་ཀྱི་མིང་ཙམ་དུ་བཀོད་ཡོད་ཀྱང་། ཚིགས་བཅད་བཅུ་བཞི་པའི་གནོད་པ་བྱེད་མཁན་ལ་བགེགས་ཞེས་པའི་མིང་ཐད་ཀར་སྦྱོར་བའི་འགྲེལ་པ་དང་ཀླུ་སྲིན་ཡི་དྭགས་སམ་དམ་སྲི་གཞན་གྱི་མིང་གིས་མཚོན་པའི་འགྲེལ་པ་གཉིས་ཡོད་པའི་ཁྱད་པར་ཡང་གསལ།།<ref name="palden-sherab" /><ref name="drakpa-gyaltsen" /><ref name="taranatha" />

== དཔྱད་གཞིའི་ཡིག་ཆ། ==
* རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།
* མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།
* ལྡོམ་བུ་བ་པདྨ་རྣམ་པར་རྒྱལ་བ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་བདུད་རྩིའི་དགའ་ཚལ།
* སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ། རྗེ་བཙུན་མ་སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་འགྲེལ་དང་དམིགས་རིམ་འཕགས་མའི་བྱིན་རླབས་གྲུ་ཆར།
* འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉེར་གཅིག་གི་རྣམ་བཤད།
* ཏཱ་ར་ནཱ་ཐ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།
* སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།
* མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།
