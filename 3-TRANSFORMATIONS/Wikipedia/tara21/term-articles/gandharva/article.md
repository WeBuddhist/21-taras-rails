'''དྲི་ཟ་'''ནི་ རྗེ་བཙུན་སྒྲོལ་མ་ལ་ཕྱག་འཚལ་བའི་བསྟོད་པ་ཉེར་གཅིག་པའི་འགྲེལ་པ་མང་པོའི་ནང་དུ་མཚན་གཟུང་བའི་སྲོག་ཆགས་ཀྱི་སྡེ་ཞིག་ཡིན་ཏེ། རྩ་བའི་ཚིགས་བཅད་ལས་འབྱུང་པོ་དང་། རོ་ལངས། གནོད་སྦྱིན་བཅས་དང་ལྷན་ཅིག་ཏུ་སྒྲོལ་མའི་མདུན་ནས་བསྟོད་པའི་ཚོགས་བཞིའི་ནང་གསེས་ཤིག་ཡིན་ཞིང་། "ཕྱག་འཚལ་བརྒྱ་བྱིན་མེ་ལྷ་ཚངས་པ། ། རླུང་ལྷ་སྣ་ཚོགས་དབང་ཕྱུག་མཆོད་མ། ། འབྱུང་པོ་རོ་ལངས་དྲི་ཟ་རྣམས་དང་། ། གནོད་སྦྱིན་ཚོགས་ཀྱིས་མདུན་ནས་བསྟོད་མ།"ཞེས་པའི་ཚིགས་བཅད་འགྲེལ་པ་མང་པོས་འདྲེན།<ref name="anon-trinle-char">མཛད་པ་པོ་མ་གསལ། སྒྲོལ་མ་ཉེར་གཅིག་པའི་བསྟོད་འགྲེལ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།</ref><ref name="anon-utpala">དངུལ་ཆུ་དྷརྨ་བྷ་དྲ། སྒྲོལ་མར་ཕྱག་འཚལ་ཉེར་གཅིག་གིས་བསྟོད་པའི་རྣམ་བཤད་ཡིད་འཕྲོག་ཨུཏྤལའི་ཆུན་པོ།</ref><ref name="palden-sherab">མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།</ref><ref name="tenzin-dhonzang">སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།</ref> འགྲེལ་པ་བཅུ་གཉིས་ཙམ་གྱིས་ཚིགས་བཅད་འདིའི་ནང་གསེས་སམ་དོན་བསྡུས་སུ་དྲི་ཟ་ཞེས་པའི་མིང་འདི་ཉིད་འདྲེན།

== གཞུང་ལུགས་སོ་སོའི་བཤད་པ། ==

'''དངུལ་ཆུ་དྷརྨ་བྷ་དྲ་'''ནས་ དྲི་ཟ་ནི་ལྷའི་དབང་པོ་བརྒྱ་བྱིན་གྱི་འཁོར་དུ་བཤད་དེ། "བརྒྱ་བྱིན་གྱི་འཁོར་དྲི་ཟ་རྣམས་དང་"ཞེས་གསུངས།<ref name="anon-utpala"/> དགེ་བཤེས་བློ་བཟང་ཟླ་བ་དང་། འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ་གཉིས་ཀྱིས་ཀྱང་མཐུན་པར་བཤད།<ref name="lobsang-dawa">དགེ་བཤེས་བློ་བཟང་ཟླ་བ། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་མཆན་འགྲེལ།</ref><ref name="sungrab-tulku">འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།</ref> མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་དང་སངས་རྒྱས་མཉན་སྤྲུལ་གཉིས་ཀྱིས་ནི་ཤར་ཕྱོགས་ཀྱི་དཀྱིལ་འཁོར་འཁོར་ལྷ་བརྒྱ་བྱིན་གྱི་སྣ་ཚོགས་ཤིང་རྟའི་འཁོར་དུ་ཞིབ་ཏུ་བཤད་དེ། "དྲི་ཟ་ནི་ལྷའི་དབང་པོ་བརྒྱ་བྱིན་གྱི་འཁོར་ཤར་ཕྱོགས་སྣ་ཚོགས་ཤིང་རྟ་སོགས་རྣམས་དང་།"ཞེས་གསུངས།<ref name="palden-sherab"/><ref name="sangye-nyentrul">སངས་རྒྱས་མཉན་སྤྲུལ། རྗེ་བཙུན་མ་སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་འགྲེལ་དང་དམིགས་རིམ་འཕགས་མའི་བྱིན་རླབས་གྲུ་ཆར།</ref>

'''རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན་'''ནས་ དྲི་ཟ་ནི་ཟུར་ཕུད་ལྔ་པས་མཚོན་པའི་སྡེ་རིགས་ཤིག་ཏུ་བཤད་དེ། "དྲི་ཟ་ནི་ཟུར་ཕུད་ལྔ་པ་ལ་སོགས་པའོ།"ཞེས་གསུངས།<ref name="drakpa-gyaltsen">རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།</ref> རྒྱལ་བ་དགེ་འདུན་གྲུབ། ཀརྨ་མཻ་ཏྲི། རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོ། མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག་བཅས་ཀྱིས་ཀྱང་མཐུན་པར་ཟུར་ཕུད་ལྔ་པས་(དྲི་ཟའི་རྒྱལ་པོར་ཡང་འབོད)མཚོན་པར་བཤད།<ref name="gendun-drub">རྒྱལ་བ་དགེ་འདུན་གྲུབ། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཊཱིཀྐ་རིན་པོ་ཆེའི་ཕྲེང་བ།</ref><ref name="karma-maitri">ཀརྨ་མཻ་ཏྲི། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པའི་བསྡུས་འགྲེལ།</ref><ref name="gendun-gyatso">རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོ། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་མའི་རྣམ་བཤད།</ref><ref name="tsultrim-namdak">མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།</ref>

'''ཏཱ་ར་ནཱ་ཐ་'''ནས་ནི་ གོང་གི་ཟུར་ཕུད་ལྔ་པའི་བཤད་སྟངས་ལས་མིང་མི་འདྲ་བ་ཞིག་གིས་དྲི་ཟ་མཚོན་ཏེ། "དྲི་ཟ་ནི་སྣ་ཚོགས་ཤིང་རྟ་ལ་སོགས་པ་རྣམས་དང་།"ཞེས་གསུངས། འགྲེལ་པ་གཞན་གང་གིས་ཀྱང་མིང་འདི་མི་གསུང་།<ref name="taranatha">ཏཱ་ར་ནཱ་ཐ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།</ref>

'''དཀོན་མཆོག་ཐབས་མཁས་'''ནས་ གོང་གི་བཤད་སྟངས་ཐམས་ཅད་ལས་མི་འདྲ་བར་དྲི་ཟ་ཞེས་པ་སྡེ་རིགས་ཀྱི་མིང་དངོས་མིན་པར་གཤིན་རྗེའི་མཚན་གཞན་ཞིག་ཏུ་བཤད་དེ། "དྲི་ཟའི་བདག་པོ་གཤིན་རྗེ་རྣམས་དང་"ཞེས་གསུངས་ལ།<ref name="konchok-thabkhe">དཀོན་མཆོག་ཐབས་མཁས། ཕྱག་འཚལ་ཉེར་གཅིག་མའི་ཊིཀྐ་འཕགས་མའི་ཞལ་ལུང་།</ref> གཞན་ཡང་"དྲི་ཟ་ཞེས་པ་བར་དོ་བའི་མིང་གི་རྣམ་གྲངས་སུ་ཆོས་མངོན་པ་ལས་གསུངས་པ་དང་། ཤི་བ་ཀུན་གྱི་གཤིན་པུ་རྗེ་ཞེས་པ་ཡང་བར་དོ་ལ་དབང་བསྒྱུར་བ་ལ་བྱེད་དགོས་པས་དྲི་ཟ་ཞེས་པ་གཤིན་རྗེ་ལ་སྦྱར་ནས་བཀོད་པ་ཡིན་པས་དཔྱད་བར་བྱའོ།"ཞེས་ཆོས་མངོན་པར་གྲགས་པའི་མིང་གི་རྣམ་གྲངས་ལ་གཞིར་བཞག་ནས་བཤད།<ref name="konchok-thabkhe"/> རྡོར་སློབ་བསྟན་དགའ་སྤྲུལ་གྱིས་ཀྱང་དྲི་ཟ་རྣམས་ལ་"སྲིད་པ་བར་དོར་འཁྱམས་པའི་དྲི་ཟ་རྣམས"ཞེས་གསུངས་ཏེ་ཕྱོགས་མཚུངས་ཤིག་བཤད་ཀྱང་། ཆོས་མངོན་པ་དང་གཤིན་རྗེའི་སྦྱོར་བ་གཉིས་ཀ་མི་གསུང་།<ref name="tenga-tulku">རྡོར་སློབ་བསྟན་དགའ་སྤྲུལ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཕན་ཡོན་དང་བཅས་པ་གསལ་བའི་མེ་ལོང་།</ref>

== རྫོགས་རིམ་གྱི་བརྡ་དོན། ==
མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་དང་ཏཱ་ར་ནཱ་ཐ་གཉིས་ཀས་དྲི་ཟ་ལ་རྫོགས་རིམ་གྱི་བརྡ་དོན་གཅིག་མཚུངས་གསུངས་ཏེ་རླུང་དུ་བཤད། མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་ནི། "འབྱུང་པོ་རྩ་དང་། རོ་ལངས་ཐིག་ལེ་དང་། དྲི་ཟ་རླུང་དང་། གནོད་སྦྱིན་རྣམ་རྟོག་སྟེ།"ཞེས་གསུངས་ལ།<ref name="palden-sherab"/> ཏཱ་ར་ནཱ་ཐས་ཀྱང་"འབྱུང་པོ་རྩ། རོ་ལངས་ཐིག་ལེ། དྲི་ཟ་རླུང་། གནོད་སྦྱིན་རྣམ་རྟོག་སྟེ།"ཞེས་གོང་དང་མཚུངས་པའི་བརྡ་དོན་བཞིར་གསུངས།<ref name="taranatha"/>

== ཕན་ཡོན། ==
ལྡོམ་བུ་བ་པདྨ་རྣམ་པར་རྒྱལ་བས་སྒྲོལ་མའི་མདུན་དུ་དྲི་ཟའི་རྒྱལ་པོ་ལྗོན་པ་རྟ་མགོ་ཅན་ལ་སོགས་པའི་དྲི་ཟ་ཚོགས་ཀྱང་སྐྲག་ཅིང་འདར་ཞིང་བསྟོད་པར་བཤད་ནས། སྒྲོལ་མ་དེ་ལ་ཕྱག་འཚལ་ན་འབྱུང་པོ་དེ་དག་གི་འཇིགས་པ་ལས་གྲོལ་བར་བཤད་དེ། "རོ་ལངས་དྲི་ཟའི་རྒྱལ་པོ་ལྗོན་པ་རྟ་མགོ་ཅན་ལ་སོགས་པའི་དྲི་ཟ་རྣམས་དང་"ཞེས་དང་། "དེ་དག་གི་འཇིགས་པ་ལས་འདི་དང་ཚེ་རབས་ཀུན་ཏུ་བྲལ་ལོ།"ཞེས་གསུངས།<ref name="pema-namgyal">ལྡོམ་བུ་བ་པདྨ་རྣམ་པར་རྒྱལ་བ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་བདུད་རྩིའི་དགའ་ཚལ།</ref>

== དབྱེ་བ། ==
སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་གིས་རྩ་བའི་བསྟོད་པའི་ཚིགས་བཅད་ལས་གཞན་པའི་གཞུང་ཞིག་(གདུགས་དཀར)ལས་དྲངས་ཏེ་གདོན་གཉེར་བརྒྱད་ཀྱི་ནང་གསེས་སུ་དྲི་ཟའི་གདོན་ཡང་གཏོགས་པར་བཤད། འགྲེལ་པ་གཞན་གང་གིས་ཀྱང་དྲི་ཟ་གདོན་གྱི་ནང་གསེས་སུ་མི་གསུང་།<ref name="tenzin-dhonzang"/>

== བསྡུས་དོན། ==
འགྲེལ་པ་མང་པོས་དྲི་ཟ་རྩ་བའི་ཚིགས་བཅད་ཀྱི་ནང་དུ་བཤད་ཀྱང་། དེའི་ངོ་བོ་ངེས་པར་ཅི་ཡིན་པའི་སྐོར་ལ་མཐུན་པའི་ལྟ་བ་གཅིག་མི་གསལ་ཏེ། བརྒྱ་བྱིན་གྱི་འཁོར་དང་། ཟུར་ཕུད་ལྔ་པས་མཚོན་པ། མིང་གཞན་ཞིག་གིས་མཚོན་པ། གཤིན་རྗེ་དང་འབྲེལ་བའི་བར་དོའི་སྲོག་ཆགས་བཅས་ལྟ་བ་བཞིར་ཐ་དད།<ref name="anon-trinle-char"/>

== དཔྱད་གཞིའི་ཡིག་ཆ། ==
* མཛད་པ་པོ་མ་གསལ། སྒྲོལ་མ་ཉེར་གཅིག་པའི་བསྟོད་འགྲེལ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།
* དངུལ་ཆུ་དྷརྨ་བྷ་དྲ། སྒྲོལ་མར་ཕྱག་འཚལ་ཉེར་གཅིག་གིས་བསྟོད་པའི་རྣམ་བཤད་ཡིད་འཕྲོག་ཨུཏྤལའི་ཆུན་པོ།
* མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།
* སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།
* དགེ་བཤེས་བློ་བཟང་ཟླ་བ། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་མཆན་འགྲེལ།
* འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།
* སངས་རྒྱས་མཉན་སྤྲུལ། རྗེ་བཙུན་མ་སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་འགྲེལ་དང་དམིགས་རིམ་འཕགས་མའི་བྱིན་རླབས་གྲུ་ཆར།
* རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།
* རྒྱལ་བ་དགེ་འདུན་གྲུབ། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཊཱིཀྐ་རིན་པོ་ཆེའི་ཕྲེང་བ།
* ཀརྨ་མཻ་ཏྲི། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པའི་བསྡུས་འགྲེལ།
* རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོ། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་མའི་རྣམ་བཤད།
* མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།
* ཏཱ་ར་ནཱ་ཐ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།
