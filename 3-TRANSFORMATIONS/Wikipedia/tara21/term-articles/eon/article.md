'''བསྐལ་པ་'''ནི་འཇིག་རྟེན་གྱི་དུས་ཚོད་ཆེན་པོའི་ཚད་གཞི་ཞིག་སྟེ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་འགྲེལ་པ་བཅུ་དྲུག་ཀུན་གྱིས་ཚིགས་བཅད་བཅུ་གསུམ་པའི་ནང་རྗེ་བཙུན་སྒྲོལ་མ་བསྐལ་པ་ཐ་མའི་མེ་ལྟར་འབར་བའི་ཕྲེང་བའི་དབུས་ན་གནས་ཤིང་ཞབས་གཡས་བརྐྱངས་གཡོན་བསྐུམས་ཀྱིས་དགྲ་ཡི་དཔུང་འཇོམས་པར་བསྟོད་པའི་དཔེར་བརྗོད་ཀྱི་ཐད་ནས་ངོས་འཛིན་མཛད་དོ།<ref name="gendun-drub">རྒྱལ་བ་དགེ་འདུན་གྲུབ་(ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་དང་པོ)། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཊཱིཀྐ་རིན་པོ་ཆེའི་ཕྲེང་བ།</ref><ref name="taranatha">ཏཱ་ར་ནཱ་ཐ་། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།</ref> འགྲེལ་པ་མང་ཆེ་བའི་ནང་བསྐལ་པ་ཞེས་བྲིས་ཡོད་ཀྱང་། དཀོན་མཆོག་ཐབས་མཁས་ཀྱི་འགྲེལ་པར་བསྐལ་བ་ཞེས་བྲིས་པའི་ཁྱད་པར་མཆིས་ཏེ། "ཕྱག་འཚལ་བའི་ཡུལ་བསྐལ་བ་ཐ་མ་སྟེ། འཇིག་དུས་ཀྱི་མེ་ལྟར་འབར་བའི་འཕྲེང་བའི་དབུས་ན་གནས་མ"ཞེས་གསུངས་སོ།།<ref name="konchok-thabkhe">དཀོན་མཆོག་ཐབས་མཁས་(མིང་གཞན་བསྟན་པ་རྒྱ་མཚོ)། ཕྱག་འཚལ་ཉེར་གཅིག་མའི་ཊིཀྐ་འཕགས་མའི་ཞལ་ལུང་།</ref>

== ངེས་ཚིག ==
བསྐལ་པ་ཐ་མ་ཞེས་པ་ནི་འཇིག་པའི་དུས་ཀྱི་མེ་སྟེ། ཉི་མ་བདུན་ཤར་བའི་སྐབས་སུ་ས་རྡོ་རི་བྲག་ཐམས་ཅད་སྲེག་པར་བྱེད་པའི་མེ་དེ་ཉིད་ལ་གོ་བ་ཡིན།།<ref name="karma-maitri">ཀརྨ་མཻ་ཏྲི། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པའི་བསྡུས་འགྲེལ།</ref><ref name="gendun-drub" /><ref name="yama-sonam">རྗེ་བཙུན་ཡ་མ་བསོད་ནམས། སྒྲོལ་མ་ཉེར་གཅིག་པའི་བསྟོད་འགྲེལ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།</ref>

== མཚན་ཉིད། ==
མེ་འདི་ནི་སྒྲོལ་མའི་ཡེ་ཤེས་དངོས་ཡིན་ཞིང་། གཉིས་སུ་མེད་པའི་ཡེ་ཤེས་དེ་ཉིད་ཁྲོ་བོའི་མེ་དཔུང་གི་རྣམ་པར་སྣང་བའོ།།<ref name="sungrab-tulku">འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།</ref><ref name="tsultrim-namdak">མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།</ref><ref name="sangye-nyentrul">སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ། རྗེ་བཙུན་མ་སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་འགྲེལ་དང་དམིགས་རིམ་འཕགས་མའི་བྱིན་རླབས་གྲུ་ཆར།</ref>

== དབྱེ་བ། ==
བསྐལ་པ་ཞེས་པའི་ཐ་སྙད་འདི་མེའི་དཔེར་བརྗོད་ཁོ་ན་ཙམ་མ་ཡིན་པར། འགྲེལ་པ་འགའ་ཞིག་གི་ནང་དོན་གཞན་ལའང་སྦྱར་ཡོད་དེ། རྗེ་བཙུན་ཡ་མ་བསོད་ནམས་ཀྱིས་སྒྲོལ་མ་ཞེས་པའི་མཚན་གྱི་འབྱུང་ཁུངས་གསུངས་སྐབས། བསྐལ་པ་དཔག་ཏུ་མེད་པའི་སྔོན་རོལ་ནས་མཚན་དེ་ལྟར་བསྔགས་པར་བཤད་ཅིང་། དེས་ལྷ་མོའི་མཛད་པ་ཐོག་མེད་ཀྱི་དུས་ནས་ཡིན་པ་སྟོན་ནོ།<ref name="yama-sonam" /> སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་གིས་ཇོ་ནང་ཏཱ་ར་ནཱ་ཐའི་ལུང་དྲངས་པའི་ནང་། བསྐལ་པ་འདི་ཉིད་ལ་འཕགས་པ་སྤྱན་རས་གཟིགས་ཀྱིས་སྒྲོལ་མའི་སྔགས་རྒྱུད་འབུམ་ཕྲག་བརྒྱ་གསུངས་པར་བཤད་དེ། གཞུང་འདིའི་སྔགས་རྒྱུད་བསྟན་པའི་དུས་ཚིགས་མཚོན་པར་མཛད་དོ།<ref name="tenzin-dhonzang">སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།</ref> ཁོང་གིས་མེའི་དཔེར་བརྗོད་འདི་ཉིད་ཚིགས་བཅད་གཞན་གྱི་དམིགས་པའི་ཚུལ་ལའང་སྦྱར་ཡོད་དེ། དཔའ་བོའི་སྟང་སྟབས་ཀྱིས་བསྐལ་པའི་མེ་ལྟར་འབར་བའི་ཀློང་དཀྱིལ་ན་བཞུགས་ཤིང་ཉི་ཟླ་འབར་བའི་སྤྱན་གྱིས་བགེགས་དཔུང་བསྲེགས་པར་མཛད་ཅེས་ཚིགས་བཅད་ཉི་ཤུ་པའི་དམིགས་པ་དང་སྦྱོར་བའི་ལུགས་ཤིག་ཀྱང་བཀོད་ཡོད།<ref name="tenzin-dhonzang" /> མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག་གིས་སྒྲོལ་མའི་སྐུ་ལུས་ནི་ཚོགས་གཉིས་ཀྱི་རྒྱ་མཚོ་བསྲུབས་པ་ལས་གྲུབ་པར་གསུངས་སྐབས། ལྷ་མོ་ཉིད་ཞི་བའི་ཏིང་ངེ་འཛིན་ལ་བསྐལ་པ་མང་པོའི་བར་དུ་གཡོ་བ་མེད་པར་བཞུགས་པར་བཤད་དོ།<ref name="tsultrim-namdak" /> དེ་བཞིན་དུ་ཁོང་གིས་སྒྲུབ་ཐབས་ཀྱི་ཡན་ལག་བདུན་པའི་གསོལ་འདེབས་དང་མཇུག་གི་བསྔོ་བའི་ཚིག་གི་ནང་དུ། སངས་རྒྱས་རྣམས་ཞིང་གི་རྡུལ་སྙེད་ཀྱི་བསྐལ་པའི་བར་དུ་མྱ་ངན་ལས་མི་འདའ་བར་བཞུགས་པར་གསོལ་བ་འདེབས་པ་དང་། བསྟན་འཛིན་གྱི་སྐྱེས་བུ་རྣམས་ཀྱི་ཞབས་པད་བསྐལ་པ་བརྒྱའི་བར་དུ་བརྟན་པར་སྨོན་པའི་ཚིག་གཉིས་ཀ་བཀོད་ཡོད།<ref name="tsultrim-namdak" /> སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་གིས་ཀྱང་སྤྱན་རས་གཟིགས་ཀྱི་མདོ་ལས་ལུང་དྲངས་ཏེ། སངས་རྒྱས་བྱེ་བ་ཁྲག་ཁྲིག་ལ་བསྐལ་བ་བྱེ་བའི་བར་དུ་མཆོད་པ་ཕུལ་བའི་བསོད་ནམས་དང་། ཕྱི་མའི་དུས་སུ་མཆོད་རྟེན་དང་སྐུ་གཟུགས་ལ་ཕྱག་གཅིག་འཚལ་བའི་ཕན་ཡོན་གཉིས་མཉམ་པར་བཤད་དོ།།<ref name="tenzin-dhonzang" />

== གཞུང་ལུགས་སོ་སོའི་བཤད་པ། ==
'''མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་'''ཀྱིས་ཚིགས་བཅད་བཅུ་གསུམ་པ་ལ་སྦས་དོན་གྱི་བཤད་པ་གཉིས་བཀོད་ཡོད་དེ། དང་པོ་རྫོགས་རིམ་མཚན་བཅས་ཀྱི་སྒོ་ནས། "བསྐལ་པ་ཐ་མའི་མེ་ལྟ་བུ་ནི་དབྱིངས་ཀྱི་རང་གཟུགས་རབ་ཚ་བ་ཡེ་ཤེས་ཀྱི་མེ་ཨ་ཤད་ཙཎྜ་ལཱིའོ།"ཞེས་གཏུམ་མོའི་མེ་དང་སྦྱར་ནས་བཤད་ཅིང་།<ref name="palden-sherab">མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།</ref> གཉིས་པ་རྫོགས་རིམ་མཚན་མེད་ཀྱི་སྒོ་ནས། རིག་སྟོང་རང་བྱུང་མངོན་དུ་གྱུར་པས་འཁྲུལ་སྣང་གི་འཛིན་ཞེན་ཐམས་ཅད་ལྷག་མེད་དུ་སྲེག་ནུས་པ་དེ་ཉིད་མཐར་ཐུག་གི་དོན་དུ་བཤད་དེ། འགྲེལ་པ་གཞན་གང་གིས་ཀྱང་འདི་དང་མཚུངས་པའི་སྦས་དོན་གྱི་བཤད་པ་བཀོད་མེད།<ref name="palden-sherab" /> '''ཇོ་ནང་ཏཱ་ར་ནཱ་ཐ་'''ཡིས་ནི་སྦས་དོན་གྱི་བཤད་པ་མ་མཛད་པར། འཇིག་དུས་ཀྱི་མེ་ལྟར་འབར་བའི་མེ་དཔུང་གི་ཕྲེང་བའི་དབུས་ན་བཞུགས་པ་ཙམ་དུ་བསྡུས་ཏེ་བཤད་དོ།།<ref name="taranatha" />

== བསྡུས་དོན། ==
མདོར་ན། ཕྱག་འཚལ་ཉེར་གཅིག་གི་འགྲེལ་པ་བཅུ་དྲུག་ཀུན་གྱིས་བསྐལ་པ་ཐ་མའི་མེ་ལྟར་འབར་བའི་དཔེར་བརྗོད་འདི་ངོས་འཛིན་མཛད་ཅིང་།<ref name="gendun-drub" /><ref name="konchok-thabkhe" /> མེ་དེ་ཉིད་སྒྲོལ་མའི་ཡེ་ཤེས་ཀྱི་རྣམ་འགྱུར་ཡིན་པར་བསྟན།<ref name="sungrab-tulku" /><ref name="tsultrim-namdak" /> གཞན་ཡང་བསྐལ་པ་ཞེས་པའི་ཐ་སྙད་འདིས་ལྷ་མོའི་མཛད་པ་ཐོག་མེད་ཀྱི་དུས་ནས་ཡིན་པ་མཚོན་པ་དང་།<ref name="yama-sonam" /> ཉམས་ལེན་གྱི་དུས་ཡུན་རིང་བ་མཚོན་པ་དང་། སངས་རྒྱས་མྱ་ངན་ལས་མི་འདའ་བར་གསོལ་བ་འདེབས་པ། དེ་བཞིན་བསོད་ནམས་ཆེན་པོའི་ཚད་གཞི་བཅས་ལའང་འགྲེལ་པ་འགའ་ཞིག་གིས་སྦྱར་ནས་བཤད་དོ།།<ref name="tsultrim-namdak" /><ref name="tenzin-dhonzang" />

== དཔྱད་གཞིའི་ཡིག་ཆ། ==
* ཏཱ་ར་ནཱ་ཐ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།
* རྒྱལ་བ་དགེ་འདུན་གྲུབ་(ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་དང་པོ)། སྒྲོལ་མ་ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཊཱིཀྐ་རིན་པོ་ཆེའི་ཕྲེང་བ།
* ཀརྨ་མཻ་ཏྲི། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པའི་བསྡུས་འགྲེལ།
* མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།
* སངས་རྒྱས་མཉན་པ་རིན་པོ་ཆེ། རྗེ་བཙུན་མ་སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་འགྲེལ་དང་དམིགས་རིམ་འཕགས་མའི་བྱིན་རླབས་གྲུ་ཆར།
