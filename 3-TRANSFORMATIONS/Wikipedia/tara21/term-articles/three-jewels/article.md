'''དཀོན་མཆོག་གསུམ་'''ནི་ རྗེ་བཙུན་སྒྲོལ་མ་ལ་ཕྱག་འཚལ་བའི་བསྟོད་པ་ཉེར་གཅིག་པའི་དགུ་པའི་ཕྱག་འཚལ་ཚིགས་བཅད་ཀྱི་ནང་དུ་སྒྲོལ་མའི་ཕྱག་གཡོན་གྱི་ཕྱག་རྒྱས་མཚོན་པར་བྱེད་པའི་མཚན་ཞིག་ཡིན། ཚིགས་བཅད་ལས་"ཕྱག་འཚལ་དཀོན་མཆོག་གསུམ་མཚོན་ཕྱག་རྒྱའི། ། སོར་མོས་ཐུགས་ཀར་རྣམ་པར་བརྒྱན་མ། ། མ་ལུས་ཕྱོགས་ཀྱི་འཁོར་ལོ་བརྒྱན་པའི། ། རང་གི་འོད་ཀྱི་ཚོགས་རྣམས་འཁྲུགས་མ།"ཞེས་འགྲེལ་པ་མང་པོས་འདྲ་བའི་ཚུལ་དུ་འདྲེན།<ref name="yama-sonam">རྗེ་བཙུན་ཡ་མ་བསོད་ནམས། སྒྲོལ་མ་ཉེར་གཅིག་པའི་བསྟོད་འགྲེལ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།</ref><ref name="sungrab-tulku">འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།</ref><ref name="tenzin-dhonzang">སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།</ref> འགྲེལ་པ་ཁ་ཅིག་གིས་ཕྱག་འཚལ་དགུ་པ་འདིར་དཀོན་མཆོག་གསུམ་མཚོན་པའི་བསྟོད་པ་ཞེས་མིང་བཏགས།།<ref name="tenzin-dhonzang"/>

== མཚན་ཉིད། ==
ཕྱག་རྒྱ་འདི་ནི་ཕྱག་གཡོན་གྱི་མཐེབ་སྲིན་གཉིས་ཀྱིས་ཨུཏྤ་ལའི་ཡུ་བ་བཟུང་ཞིང་མཛུབ་མོ་གུང་མོ་མཐེའུ་ཆུང་གསུམ་གནམ་དུ་བསྒྲེང་བའི་ཚུལ་དུ་ཡོད་པར་འགྲེལ་པ་མང་པོས་བཤད།<ref name="yama-sonam"/><ref name="palden-sherab">མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།</ref> འོན་ཀྱང་འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུས་སོར་མོའི་གནས་ས་གཞན་དང་མི་འདྲ་བར་བཤད་དེ། "རྗེ་བཙུན་སྒྲོལ་མའི་ཕྱག་གཡོན་པའི་མཐེ་མོ་དང་གུང་མོ་གཉིས་ཀྱིས་མེ་ཏོག་ཨུཏྤལའི་ཡུ་བ་བཟུངས་ཤིང་། མཛུབ་མོ་དང་སྲིན་ལག མཐེའུ་ཆུང་བཅས་གསུམ་སྒྲེང་བ"ཞེས་གུང་མོ་དང་སྲིན་ལག་གི་བྱ་བ་བརྗེས་ནས་བཤད།།<ref name="sungrab-tulku"/>

སྐྱེད་རིམ་གྱི་དམིགས་པར་ཕྱག་གཡོན་གྱི་ཨུཏྤལ་བསྣམས་པའི་ཟེའུ་འབྲུའི་སྟེང་དུ་འོད་ཀྱི་འཁོར་ལོ་འབར་བ་ཞིག་ཀྱང་ཡོད་པར་མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་ཀྱིས་བཤད།།<ref name="palden-sherab"/>

== དབྱེ་བ། ==
"དཀོན་མཆོག་གསུམ་མཚོན"པའི་དོན་ལ་ཕྱི་ནང་གཉིས་སུ་ཕྱེ་སྟེ། ཕྱི་རོལ་གྱི་དོན་ནི་ཕྱག་རྒྱས་མཚོན་པའི་སངས་རྒྱས་ཆོས་དགེ་འདུན་གསུམ་ཡིན་ལ། ནང་གི་སྦས་དོན་ནི་རྫོགས་རིམ་གྱི་སྐབས་སུ་ཁུ་རྡུལ་རླུང་གསུམ་ཡིན་པར་ཇོ་ནང་ཏཱ་ར་ནཱ་ཐ་དང་མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་གཉིས་ཀས་ཚིག་གཅིག་མཚུངས་སུ་བཤད་དེ། "སྦས་དོན་ནི། དཀོན་མཆོག་གསུམ་མཚོན་ནི་ཁུ་རྡུལ་རླུང་གསུམ་སྟེ།"ཞེས་གསུངས།།<ref name="taranatha">ཏཱ་ར་ནཱ་ཐ་། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།</ref><ref name="palden-sherab"/>

== གཞུང་ལུགས་སོ་སོའི་བཤད་པ། ==

'''རྗེ་བཙུན་ཡ་མ་བསོད་ནམས་'''ནས་: ཕྱག་རྒྱ་འདིའི་རྒྱུ་དང་བྱ་བ་སོ་སོར་ཕྱེ་སྟེ་རྒྱུ་ནི་སངས་རྒྱས་དཀོན་མཆོག་དང་ཆོས་དཀོན་མཆོག་གཉིས་ལས་བྱུང་བ་ཡིན་ལ། བྱ་བ་ནི་དགེ་འདུན་རྗེས་སུ་བསྐྱང་བའི་དོན་སྟོན་པ་ཡིན་པར་བཤད་དེ། འདི་ནི་འགྲེལ་པ་གཞན་གང་ཡང་མི་མཐུན་པའི་བཤད་ཚུལ་ཞིག་ཡིན།།<ref name="yama-sonam"/>

'''འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ་'''ནས་: ཕྱག་འཚལ་བའི་དོན་རྗེ་བཙུན་སྒྲོལ་མ་ཉིད་དཀོན་མཆོག་གསུམ་ལ་སྒོ་གསུམ་གུས་པས་འདུད་པའི་མཆོད་པའི་ཡུལ་དུ་བཤད།།<ref name="sungrab-tulku"/>

'''སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་'''ནས་: འདི་དང་འགལ་བར་སྒྲོལ་མ་ཉིད་དཀོན་མཆོག་གསུམ་གྱི་ངོ་བོར་བཤད་དེ། སྐུ་དགེ་འདུན་དང་གསུང་དམ་ཆོས་ཐུགས་སངས་རྒྱས་སུ་སྦྱར་ནས་དཀོན་མཆོག་ཀུན་འདུས་པར་བཀོད།།<ref name="tenzin-dhonzang"/>

'''ཇོ་ནང་ཏཱ་ར་ནཱ་ཐ་'''ནས་: ཕྱག་རྒྱ་འདི་ཉིད་སྒྲོལ་མའི་དམ་ཚིག་གི་ཕྱག་རྒྱ་ཉིད་དུ་ངོས་འཛིན་བྱེད་དེ། འདི་འགྲེལ་པ་གཞན་གང་གིས་ཀྱང་མི་གསུང་བའི་ངོས་འཛིན་ཁྱད་པར་ཅན་ཞིག་ཡིན།།<ref name="taranatha"/>

'''དཀོན་མཆོག་ཐབས་མཁས་'''ནས་: རྒྱལ་བ་དགེ་འདུན་གྲུབ་ཀྱི་སྒྲོལ་དཀར་བསྟོད་པའི་ཚིགས་བཅད་འདྲེན་ཏེ་ཕྱག་གི་ཨུཏྤལ་གྱིས་དུས་གསུམ་སངས་རྒྱས་མཚོན་ཞིང་ཕྱག་རྒྱ་རང་ཉིད་ཀྱིས་དཀོན་མཆོག་མ་ལུས་པ་འདུས་པའི་ངོ་བོར་སྟོན་པར་བཤད།།<ref name="konchok-thabkhe">དཀོན་མཆོག་ཐབས་མཁས་(མིང་གཞན་བསྟན་པ་རྒྱ་མཚོ)། ཕྱག་འཚལ་ཉེར་གཅིག་མའི་ཊིཀྐ་འཕགས་མའི་ཞལ་ལུང་།</ref>

'''མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་'''ནས་: རྫོགས་རིམ་མཚན་མེད་ཀྱི་མཐར་ཐུག་གི་དོན་དུ་ཡང་སྒོ་གསུམ་སྣང་གྲགས་རིག་གསུམ་རྡོ་རྗེ་གསུམ་གྱི་ངོ་བོ་ཉིད་"དཀོན་མཆོག་གསུམ་མཚོན"པའི་ངོ་བོར་བཤད།<ref name="palden-sherab"/> ཕྱག་རྒྱ་འདི་དགུ་པའི་ཕྱག་འཚལ་ཁོ་ནར་མ་ཟད་སྒྲོལ་མའི་སྤྲུལ་པ་ཉེར་གཅིག་ཡན་ལག་གི་བསྐྱེད་རིམ་བཅོ་བརྒྱད་ཙམ་གྱི་ནང་དུའང་སླར་ཡང་སླར་ཡང་འབྱུང་བར་བཤད་དེ། དཔེར་ན་གཙུག་ཏོར་རྣམ་པར་རྒྱལ་མ་དང་མི་ཕམ་གཙུག་ཏོར་གདུགས་དཀར་མོའི་སྐབས་སུའང་ཨུཏྤལ་གྱི་སྟེང་དུ་སོ་སོའི་ཕྱག་མཚན་ཁྱད་པར་ཅན་བཞག་པར་བཤད།།<ref name="palden-sherab"/>

'''མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག་'''ནས་: ཚིགས་བཅད་དགུ་པའི་ཚིག་རྐང་གསུམ་པ་བཞི་པ་འགྲེལ་པ་གཞན་རྣམས་དང་མི་འདྲ་བར་སེང་ལྡེང་ནགས་ཀྱི་སྒྲོལ་མའི་ལོ་རྒྱུས་དང་སྦྱར་ཏེ་འདྲེན་པའི་ཡིག་ཆའི་ཁྱད་པར་ཞིག་ཏུ་གནས།<ref name="tsultrim-namdak">མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།</ref> སྒྲུབ་ཐབས་ཀྱི་སྐབས་སུ་དཀོན་མཆོག་གསུམ་ཐུན་མོང་གི་སྐྱབས་ཡུལ་དང་། གསང་སྔགས་རྡོ་རྗེ་ཐེག་པའི་རྩ་བ་གསུམ་གྱི་ལྷ་ཚོགས་མ་ལུས་པ་ཀུན་འདུས་པའི་བདག་ཉིད་རྗེ་བཙུན་འཕགས་མ་སྒྲོལ་མ་ལ་སྐྱབས་སུ་འགྲོ་བར་བཤད་ཅིང་། སྐྱབས་འགྲོའི་ཕན་ཡོན་ཡང་ནང་པའི་གྲལ་དུ་ཚུད་ཅིང་དཀོན་མཆོག་གསུམ་གྱིས་སྲུང་སྐྱོབ་བྱེད་པར་བཤད།།<ref name="tsultrim-namdak"/>

== བསྡུས་དོན། ==
འགྲེལ་པ་མང་པོའི་ནང་དུ་དཀོན་མཆོག་གསུམ་ནི་སྒྲོལ་མའི་ཕྱག་གཡོན་གྱི་ཕྱག་རྒྱས་མཚོན་པའི་སངས་རྒྱས་ཆོས་དགེ་འདུན་གསུམ་ཡིན་ཞིང་། ཁ་ཅིག་གིས་ནང་གི་སྦས་དོན་དུ་ཁུ་རྡུལ་རླུང་གསུམ་དུའང་བཤད། སྒྲོལ་མ་ཉིད་དཀོན་མཆོག་གསུམ་དང་ཇི་ལྟར་འབྲེལ་བའི་ཐད་ཡང་མཆོད་པའི་ཡུལ་ལམ་ཡང་ན་ངོ་བོ་ཉིད་དུ་འགྲེལ་པ་སོ་སོར་མི་མཐུན་པའི་བཤད་ཚུལ་ཡོད།།<ref name="sungrab-tulku"/><ref name="tenzin-dhonzang"/>

== དཔྱད་གཞིའི་ཡིག་ཆ། ==
* རྗེ་བཙུན་ཡ་མ་བསོད་ནམས། སྒྲོལ་མ་ཉེར་གཅིག་པའི་བསྟོད་འགྲེལ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།
* འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།
* སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།
* ཏཱ་ར་ནཱ་ཐ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།
* དཀོན་མཆོག་ཐབས་མཁས་(མིང་གཞན་བསྟན་པ་རྒྱ་མཚོ)། ཕྱག་འཚལ་ཉེར་གཅིག་མའི་ཊིཀྐ་འཕགས་མའི་ཞལ་ལུང་།
* མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།
* མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།
