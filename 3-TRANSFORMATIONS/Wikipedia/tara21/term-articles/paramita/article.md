'''ཕ་རོལ་ཕྱིན་པ་'''ནི་ཐེག་པ་ཆེན་པོའི་ལམ་གྱི་ཉམས་ལེན་གཙོ་བོར་གྱུར་པའི་ཡོན་ཏན་དྲུག་ལ་འགའ་ཞིག་བཞིར་སྣོན་ནས་བཅུར་བགྲང་བའི་ཆོས་ཚན་ཞིག་ཡིན་ཏེ། རྗེ་བཙུན་སྒྲོལ་མ་ལ་ཕྱག་འཚལ་ཉེར་གཅིག་གིས་བསྟོད་པའི་གསུམ་པའི་ཚིགས་བཅད་ནས་སྦྱིན་པ་ལ་སོགས་པ་དྲུག་པོ་རྗེ་བཙུན་མ་ཉིད་ཀྱི་སྤྱོད་ཡུལ་དུ་བཀོད་དོ།<ref name="tenzin-dhonzang">སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།</ref> བཞི་པའི་ཚིགས་བཅད་ནས་"ཕྱག་འཚལ་དེ་བཞིན་གཤེགས་པའི་གཙུག་ཏོར། ། མཐའ་ཡས་རྣམ་པར་རྒྱལ་བར་སྤྱོད་མ། ། མ་ལུས་ཕ་རོལ་ཕྱིན་པ་ཐོབ་པའི། ། རྒྱལ་བའི་སྲས་ཀྱིས་ཤིན་ཏུ་བསྟེན་མ།" ཞེས་གསུངས་པ་འདི་ལ་འགྲེལ་པ་བཅུ་དྲུག་ཀུན་གྱིས་ཕ་རོལ་ཕྱིན་པ་བཅུ་དང་ས་བཅུའི་གནས་སྐབས་སུ་སྦྱར་ནས་བཤད་དོ།།<ref name="tenzin-dhonzang" /><ref name="palden-sherab">མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།</ref><ref name="konchok-thabkhe">དཀོན་མཆོག་ཐབས་མཁས་(མིང་གཞན་བསྟན་པ་རྒྱ་མཚོ)། ཕྱག་འཚལ་ཉེར་གཅིག་མའི་ཊིཀྐ་འཕགས་མའི་ཞལ་ལུང་།</ref>

== དབྱེ་བ། ==
དབྱེ་ཚུལ་ཐད་ནས་ཕ་རོལ་ཕྱིན་པ་བཅུ་པོ་ནི་སྦྱིན་པ་དང་། ཚུལ་ཁྲིམས་དང་། བཟོད་པ་དང་། བརྩོན་འགྲུས་དང་། བསམ་གཏན་དང་། ཤེས་རབ་དང་། ཐབས་དང་། སྟོབས་དང་། སྨོན་ལམ་དང་། ཡེ་ཤེས་ཕར་ཕྱིན་བཅུ་པོར་བགྲངས་ཤིང་ས་བཅུའི་མིང་དང་ཡང་སྦྱར་ནས་བཤད།<ref name="palden-sherab" /> ས་རེ་རེར་ཕར་ཕྱིན་རེ་རེ་འཕེལ་བའི་ཚུལ་གྱིས་ས་བཅུ་པའི་བྱང་སེམས་རྣམས་ཀྱིས་ཤིན་ཏུ་བསྟེན་པར་ཡང་བཤད་དོ།།<ref name="konchok-thabkhe" />

འོན་ཀྱང་ཕར་ཕྱིན་གྱི་གྲངས་དང་དབྱེ་ཚུལ་ལ་འགྲེལ་པ་སོ་སོས་མི་འདྲ་བའི་ཚུལ་དུའང་བཤད་དེ། རྗེ་བཙུན་ཡ་མ་བསོད་ནམས་ཀྱིས་གསུམ་པའི་ཚིགས་བཅད་ཀྱི་ཐད་ནས་"ཞི་བའི་དོན་ལ་འགའ་ཞིག་གིས་ཤེས་རབ་ཀྱི་ཕར་ཕྱིན་ལ་སྦྱར་བ་དང་། གཞན་དག་ཕར་ཕྱིན་བཅུའི་མི་མཐུན་ཕྱོགས་ཞི་བའི་དོན་དུ་བྱས་ནས་སྤྱོད་ཡུལ་གྱིས་ཤེས་རབ་བསྟན་པར་གསུངས་སོ།" ཞེས་འགྲེལ་པ་སོ་སོའི་བཤད་ཚུལ་མི་མཐུན་པར་བཀོད།<ref name="yama-sonam">རྗེ་བཙུན་ཡ་མ་བསོད་ནམས། སྒྲོལ་མ་ཉེར་གཅིག་པའི་བསྟོད་འགྲེལ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།</ref> རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོས་ཀྱང་ཚིགས་བཅད་གཅིག་གི་ཐད་ནས་སྤངས་པ་དང་། བཟོད་པ་དང་། བསམ་གཏན་དང་། དེ་ཁོ་ན་ཉིད་ཀྱི་སྤྱོད་ཡུལ་ཅན་གྱི་ཤེས་རབ་བཅས་ཀྱིས་ཕར་ཕྱིན་དྲུག་ཡོངས་སུ་རྫོགས་པའི་ཚུལ་གཞན་ཞིག་བཤད་དོ།<ref name="gendun-gyatso">རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོ (ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་གཉིས་པ)། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་མའི་རྣམ་བཤད།</ref> དཀོན་མཆོག་ཐབས་མཁས་ཀྱིས་ནི་ཤེས་རབ་ཀྱི་ཕར་ཕྱིན་ཉིད་སྒྲོལ་མའི་ངོ་བོར་ངོས་འཛིན་བྱས་ནས་སྦྱིན་པ་སོགས་ལྔ་པོ་དེའི་སྤྱོད་ཡུལ་དུ་བཤད་དོ།<ref name="konchok-thabkhe" /> མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག་གིས་ནི་གཞན་ཡང་ཚིགས་བཅད་གཅིག་ཉིད་བྱང་ཕྱོགས་ཀྱི་ཆོས་སུམ་ཅུ་རྩ་བདུན་གྱི་ནང་ཚན་དུའང་བཤད་དོ།།<ref name="tsultrim-namdak">མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།</ref>

== ཕྱག་འཚལ་བཞི་པའི་ཕ་རོལ་ཕྱིན་པ་བཅུ་དང་ས་བཅུ། ==
གཞུང་འདིའི་བཞི་པའི་ཚིགས་བཅད་ཀྱིས་གཙུག་ཏོར་རྣམ་པར་རྒྱལ་མའི་ལྷ་མོར་ཕྱག་འཚལ་བའི་སྐབས་སུ་མ་ལུས་ཕ་རོལ་ཕྱིན་པ་ཐོབ་པའི་ཞེས་གསུངས་པ་འདི་ལ་འགྲེལ་པ་བཅུ་དྲུག་ཀུན་གྱིས་ཕ་རོལ་ཕྱིན་པ་བཅུ་ཐམས་ཅད་ས་བཅུའི་གནས་སྐབས་སུ་མཉམ་དུ་ཐོབ་པའི་དོན་དུ་བཤད་དེ། གསུམ་པའི་ཚིགས་བཅད་ཀྱི་ཕར་ཕྱིན་དྲུག་ལས་ལྷག་པའི་གོང་བུ་ཞིག་ཏུ་བགྲངས།<ref name="tenzin-dhonzang" /><ref name="drakpa-gyaltsen">རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།</ref><ref name="konchok-thabkhe" /> དཀོན་མཆོག་ཐབས་མཁས་ཀྱིས་ནི་ས་རང་རང་གི་ངོས་སྐལ་གྱི་ཕར་ཕྱིན་གོང་འཕེལ་དུ་འཕེལ་བའི་ཚུལ་གྱིས་ས་བཅུ་པའི་རྒྱལ་སྲས་རྣམས་ཀྱིས་ཤིན་ཏུ་བསྟེན་པར་ཡང་བཤད་དོ།<ref name="konchok-thabkhe" /> མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་ཀྱིས་ཀྱང་སྤངས་རྟོགས་མ་ལུས་པ་ཡོངས་སུ་རྫོགས་པའི་སྒོ་ནས་ཕར་ཕྱིན་བཅུ་དང་ས་བཅུའི་ཡེ་ཤེས་མཉམ་དུ་ཐོབ་པར་བཤད་ལ།<ref name="palden-sherab" /> དཀོན་མཆོག་ཐབས་མཁས་ཀྱིས་གསུམ་པ་དང་བཞི་པའི་ཚིགས་བཅད་གཉིས་ཀྱི་ཁྱད་པར་ལའང་བརྟག་དཔྱོད་མཛད་དེ། གསུམ་པ་ནི་ཤེས་རབ་ཀྱི་ཕར་ཕྱིན་ལ་ཕར་ཕྱིན་ལྔ་གྲོགས་སུ་གྱུར་ཚུལ་གྱིས་བསྟོད་པ་ཡིན་ལ། བཞི་པ་ནི་དུས་གསུམ་གྱི་འཕགས་པ་སྐྱེད་ཅིང་གསོ་བའི་ཡུམ་གྱི་ཚུལ་གྱིས་བསྟོད་པ་ཡིན་པར་བཤད་དོ།།<ref name="konchok-thabkhe" />

== སྦས་དོན་རྫོགས་རིམ་གྱི་བཤད་པ། ==
འགྲེལ་པ་གཉིས་ཀྱིས་ཕར་ཕྱིན་བཅུ་པོ་དེ་ཉིད་ལུས་ཀྱི་རླུང་བཅུ་དག་པའི་སྦས་དོན་དུའང་བཤད་དེ། མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ་དང་ཇོ་ནང་ཏཱ་ར་ནཱ་ཐ་གཉིས་ཀས་ཕར་ཕྱིན་བཅུ་པོ་རླུང་བཅུ་གནས་དག་པའི་ངོ་བོར་བཤད་ནས་ཡེ་ཤེས་ཆོས་སྐུ་ནི་རྒྱལ་བ་སྲས་བཅས་ཀྱི་ཡུམ་ཆེན་ཡིན་པར་མཐུན་པར་གསུངས་སོ།།<ref name="palden-sherab" /><ref name="taranatha">ཏཱ་ར་ནཱ་ཐ་། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།</ref>

== རྒྱུའི་གནས་སྐབས་སུ་སྒྲོལ་མའི་སྐུར་འགྱུར་ཚུལ། ==
འགྲེལ་པ་འགས་སྒྲོལ་མའི་སྐུ་དང་ཡོན་ཏན་ཉིད་ཕར་ཕྱིན་ཚོགས་སུ་ཉམས་སུ་ལེན་པའི་རྒྱུ་ལས་བྱུང་བར་བཤད་དེ། ཕར་ཕྱིན་དྲུག་སྤྱད་པ་ལས་སྒྲོལ་མའི་སྐུ་ཐོབ་ཅིང་ཕར་ཕྱིན་དྲུག་ལ་བརྟེན་ནས་མངོན་པར་རྫོགས་པར་སངས་རྒྱས་པར་ཡང་བཤད་ལ། ཕར་ཕྱིན་དྲུག་གི་སྤྱོད་པའི་སྒོ་ནས་དབང་བཅུའི་ཡོན་ཏན་མངོན་དུ་བྱས་པར་ཡང་བཤད་དོ།<ref name="drakpa-gyaltsen" /><ref name="tenga-tulku">རྡོར་སློབ་བསྟན་དགའ་སྤྲུལ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཕན་ཡོན་དང་བཅས་པ་གསལ་བའི་མེ་ལོང་།</ref><ref name="palden-sherab" /> འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུས་ནི་ཕར་ཕྱིན་དྲུག་པོ་སྐྱོན་དྲུག་གི་གཉེན་པོའི་ཚུལ་དུའང་བཤད་དེ། སེར་སྣའི་གཉེན་པོར་སྦྱིན་པ་དང་། ལེ་ལོའི་གཉེན་པོར་བརྩོན་འགྲུས་དང་། ཚུལ་འཆལ་གྱི་གཉེན་པོར་བསྲུང་དཀའ་བ་ཐུབ་པའི་ཚུལ་ཁྲིམས་ལ་སོགས་པར་ཕར་ཕྱིན་དྲུག་ཆར་ལ་གཉེན་པོའི་ཐབས་སོ་སོར་བཤད་དོ།།<ref name="sungrab-tulku">འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།</ref>

== ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་མར་ངོས་འཛིན་པ། ==
འགྲེལ་པ་མང་པོས་སྒྲོལ་མ་ཉིད་ཕར་ཕྱིན་དྲུག་གི་ནང་གསེས་ཙམ་མིན་པར་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ཉིད་དུ་ངོས་འཛིན་བྱེད་དེ། སངས་རྒྱས་ཐམས་ཅད་ཤེར་ཕྱིན་ལ་བརྟེན་ནས་འཁྲུངས་པའི་ཡུམ་མཆོག་ཏུའང་བཤད་དོ།<ref name="pema-namgyal">ལྡོམ་བུ་བ་པདྨ་རྣམ་པར་རྒྱལ་བ་། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་བདུད་རྩིའི་དགའ་ཚལ།</ref><ref name="sungrab-tulku" /><ref name="konchok-thabkhe" /> སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་གིས་ཕར་ཕྱིན་མཐའ་དཔྱོད་དྲངས་ཏེ་"རང་བཞིན་གྱི་ཤེར་ཕྱིན། རང་བཞིན་གྱི་ཡུམ། རང་བཞིན་གྱི་མྱང་འདས། རང་བཞིན་གྱི་ཆོས་སྐུ" ཞེས་ཤེར་ཕྱིན་དང་ཡུམ་དང་མྱང་འདས་དང་ཆོས་སྐུ་དོན་གཅིག་ཏུ་གསལ་བར་བཤད་དོ།།<ref name="tenzin-dhonzang" />

== བསྡུས་དོན། ==
འགྲེལ་པ་བཅུ་དྲུག་ཀུན་གྱིས་ཕ་རོལ་ཕྱིན་པ་ཞེས་པ་ལ་ཐོག་མར་ཕར་ཕྱིན་དྲུག་གི་ཚུལ་དུ་བཤད་ཀྱང་། གཞུང་གི་བཞི་པའི་ཚིགས་བཅད་ཐད་ནས་ཕར་ཕྱིན་བཅུ་དང་ས་བཅུའི་གནས་སྐབས་སུ་སྦྱར་ནས་བཤད་པར་མཐུན།<ref name="tenzin-dhonzang" /><ref name="palden-sherab" /> འགའ་ཞིག་གིས་སྒྲོལ་མའི་སྐུ་དང་ཡོན་ཏན་ཕར་ཕྱིན་ཚོགས་ཀྱི་རྒྱུ་ལས་བྱུང་བར་བཤད་ལ།<ref name="drakpa-gyaltsen" /><ref name="tenga-tulku" /> འགའ་ཞིག་གིས་སྒྲོལ་མ་ཉིད་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་ངོ་བོར་ངོས་འཛིན་བྱེད་ཅིང་།<ref name="pema-namgyal" /><ref name="sungrab-tulku" /> འགྲེལ་པ་གཉིས་ཀྱིས་ནི་སྦས་དོན་གྱི་ཚུལ་དུ་རླུང་བཅུ་ཕར་ཕྱིན་བཅུར་བཤད་དོ།།<ref name="palden-sherab" /><ref name="taranatha" />

== དཔྱད་གཞིའི་ཡིག་ཆ། ==
* རྗེ་བཙུན་གྲགས་པ་རྒྱལ་མཚན། སྒྲོལ་མ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་བཤད་གསལ་བའི་འོད་ཟེར།
* རྒྱལ་བ་དགེ་འདུན་རྒྱ་མཚོ (ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་གཉིས་པ)། ཕྱག་འཚལ་སྒྲོལ་མ་ཉེར་གཅིག་མའི་རྣམ་བཤད།
* དཀོན་མཆོག་ཐབས་མཁས་(མིང་གཞན་བསྟན་པ་རྒྱ་མཚོ)། ཕྱག་འཚལ་ཉེར་གཅིག་མའི་ཊིཀྐ་འཕགས་མའི་ཞལ་ལུང་།
* མཁན་ཆེན་དཔལ་ལྡན་ཤེས་རབ། རྗེ་བཙུན་སྒྲོལ་མའི་བསྟོད་པ་ཉི་ཤུ་རྩ་གཅིག་གི་ཚིག་དོན་རྣམ་པར་འགྲེལ་བ་དད་བརྩོན་བྱང་ཆུབ་སེམས་མཆོག་གི་པདྨའི་གཞོན་ནུ་ཁ་འབྱེད་པའི་ཐབས་ཤེས་ཉི་ཟླའི་འཛུམ་རླབས།
* ལྡོམ་བུ་བ་པདྨ་རྣམ་པར་རྒྱལ་བ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་བདུད་རྩིའི་དགའ་ཚལ།
* འབྲས་ཕ་ར་གྲྭ་སྨད་གསུང་རབ་སྤྲུལ་སྐུ། སྒྲོལ་མ་ཉི་ཤུ་རྩ་གཅིག་གི་རྣམ་བཤད།
* ཏཱ་ར་ནཱ་ཐ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ།
* རྡོར་སློབ་བསྟན་དགའ་སྤྲུལ། ཕྱག་འཚལ་ཉེར་གཅིག་གི་ཕན་ཡོན་དང་བཅས་པ་གསལ་བའི་མེ་ལོང་།
* སེར་སྨད་གཙང་དགེ་བཤེས་བསྟན་འཛིན་དོན་བཟང་། སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་འགྲེལ་སྙིང་གི་ནོར་བུ།
* མཁན་པོ་ཚུལ་ཁྲིམས་རྣམ་དག། སྒྲོལ་འགྲེལ་ཚོགས་གཉིས་རྒྱ་མཚོར་འཇུག་པའི་གྲུ་གཟིངས།
* རྗེ་བཙུན་ཡ་མ་བསོད་ནམས། སྒྲོལ་མ་ཉེར་གཅིག་པའི་བསྟོད་འགྲེལ་འཕྲིན་ལས་ཆར་དུ་སྙིལ་བའི་སྤྲིན་ཕུང་།
