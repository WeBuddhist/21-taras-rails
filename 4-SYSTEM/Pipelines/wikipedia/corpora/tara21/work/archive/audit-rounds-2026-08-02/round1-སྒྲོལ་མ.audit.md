# Audit — སྒྲོལ་མ

**Verdict: fix** — **does not pass**

- ⛔ [blocking] **dropped-qualifier** — The draft changes 'three different scholars' (མཁས་པ་མི་འདྲ་བ་གསུམ་) to 'many different scholars' (མཁས་པ་མི་འདྲ་བ་མང་པོ་), exaggerating the consensus.
  > སྒྲོལ་མ་ཞེས་པའི་མིང་གི་ངེས་ཚིག་ལ་མཁས་པ་མི་འདྲ་བ་མང་པོས་མཐུན་པར། སེམས་ཅན་སྡུག་བསྔལ་གྱི་རྒྱ་མཚོའམ་འཁོར་བའི་སྡུག་བསྔལ་ལས་སྒྲོལ་ཞིང་སྐྱོབ་པའི་དོན་དུ་བཤད་དོ།
- ⛔ [blocking] **added-fact** — The draft adds the assertion 'and no one denies/disputes it' (སུས་ཀྱང་མ་བསྙོན་པའོ), which is not supported by the claim.
  > མིང་སྒྲོལ་མ་ཞེས་པའི་ངེས་ཚིག་ལ། མཁས་པ་མི་འདྲ་བ་གསུམ་གྱིས་མཐུན་པར་བཤད་དེ། སྡུག་བསྔལ་གྱི་རྒྱ་མཚོ་ལས་སྒྲོལ་བ་འམ། སེམས་ཅན་ཐམས་ཅད་སངས་རྒྱས་ཀྱི་ས་ལས་སྒྲོལ་བར་མཛད་པ་འམ། འཁོར་བའི་སྡུག་བསྔལ་ལས་སྐྱོབ་པ་ཞེས་འགྲེལ་ལ། གསུམ་ཀ་མིང་གི་དོན་ལ་མཐུན་ཞིང་སུས་ཀྱང་མ་བསྙོན་པའོ།
- ⛔ [blocking] **added-fact** — The draft asserts that Gendun Drupa assigned a different name to each verse of praise (བསྟོད་པའི་ཚིག་རེ་རེའི་མཚན་ལ་མིང་གཞན་སོ་སོ་བཏགས་ཏེ), which is an unsupported generalization.
  > ཏཱ་ལའི་བླ་མ་སྐུ་ཕྲེང་དང་པོ་རྒྱལ་བ་དགེ་འདུན་གྲུབ་ཀྱིས་མཛད་པའི་འགྲེལ་བཤད་ལས། བསྟོད་པའི་ཚིག་རེ་རེའི་མཚན་ལ་མིང་གཞན་སོ་སོ་བཏགས་ཏེ། ཚིག་གཉིས་པར་དཀར་མོ་མདངས་ལྡན་སྒྲོལ་མ་ཞེས་དང་། ཚིག་བཅུ་གཅིག་པར་བདེ་བ་སྒྲུབ་པའི་སྒྲོལ་མ་ཞེས་དང་ཧཱུཾ་སྒྲ་སྒྲོགས་པའི་སྒྲོལ་མ་ཞེས། ཚིག་བཅུ་བདུན་པར་དབང་མཆོག་སྟེར་བའི་སྒྲོལ་མ་ཞེས་སོ་སོར་གསུངས་སོ།
