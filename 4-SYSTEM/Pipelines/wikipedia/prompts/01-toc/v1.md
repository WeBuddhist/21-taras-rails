## ས་བཅད་ནི་གང་ཡིན།

འགྲེལ་པ་མཁན་གྱིས་རང་གི་གཞུང་གི་དབྱེ་བ་བརྗོད་པའི་ཚིག་ལ་ས་བཅད་ཟེར། རྣམ་པ་གཉིས་ཡོད།

**རིགས་དང་པོ། གྲངས་སྟོན་པའི་ཚིག** (ཕ་མའི་གནས་སུ་བྱུང་སྟེ། བུའི་གྲངས་དང་མིང་སྟོན།)
```
བསྟོད་པ་འདི་ལ་དོན་གཉིས་ཏེ། བསྟོད་པ་དངོས་དང་ཕན་ཡོན་ནོ།།      ← གྲངས་ ༢། མིང་གཉིས་བསྟན།
དང་པོ་ལ་གསུམ་སྟེ།                                          ← གྲངས་ ༣། མིང་མ་བསྟན།
```

**རིགས་གཉིས་པ། གནས་སྟོན་པའི་ཚིག** (བུ་རང་ཉིད་འགོ་ཚུགས་སའི་གནས་སུ་བྱུང་།)
```
དང་པོ་ནི།            ← གོ་རིམ་ཙམ་སྟོན།
གཉིས་པ་ཕན་ཡོན་ནི།    ← གོ་རིམ་དང་མིང་གཉིས་ཀ་སྟོན།
```

ས་བཅད་**མ་ཡིན་པ**། ལུང་འདྲེན་དང་། རྩ་བའི་ཚིགས་བཅད་དང་། གྲངས་ཀ་བྱུང་ཙམ་གྱི་ཐ་མལ་གྱི་ཚིག་རྣམས། འདི་དོན་ལ་བརྟགས་ནས་ཐག་གཅོད་དགོས་པ་ལས། གཟུགས་ལ་བལྟས་ནས་མིན།

## ཁྱོད་ཀྱིས་སྤྲོད་དགོས་པ།

- `body_start_line` — སྡེ་ཚན་དེའི་**ནང་དོན་འགོ་ཚུགས་སའི་ཐིག་གྲངས།** གཤམ་གྱི་ཡི་གེར་ཐིག་གྲངས་བཀོད་ཡོད། དེ་ལས་ལེན། གནས་སྟོན་པའི་ཚིག་ (`དང་པོ་ནི།`) ཡོད་ན་དེའི་ཐིག་གྲངས་ཉིད་ལེན།
- `depth` — རིམ་པ། གཞུང་གི་དབྱེ་བ་ཆེ་ཤོས་ནི་ ༡ ཡིན། དེའི་བུ་ནི་ ༢ ཡིན། དེ་བཞིན་དུ།
