# Spine map — sangye-nyentrul

> Routing index only. This file records **which of this commentary's own TOC nodes hold
> which canonical spine slot's content** — nothing about what the claims say. It never
> quotes, interprets, or restates a claim; `assemble_packet.py` copies the claim text
> itself verbatim out of `2-RAILS/Claims/raw/tree-guided/sangye-nyentrul.md` at packet time.
> Every claim in that file has exactly one disposition below.

**Structure of this commentary.** A flat, strictly regular tree: node `1` glosses the root
text's own opening invocation line (`^I-1`, the "OM, homage to the reverend noble Tārā"
formula) rather than any homage, so it sits outside the registered spine. Nodes `2`–`22`
are the twenty-one homages in exact ordinal correspondence with the root text's `^1-1`–`^1-21`
— each node's title itself opens with the Tibetan ordinal numeral (`༡`…`༢༡`) followed by the
homage's own first line quoted verbatim from the root verse (e.g. node `2`'s title
`༡ ཕྱག་འཚལ་སྒྲོལ་མ་མྱུར་མ་དཔའ་མོ` reproduces `^1-1`'s own opening line character-for-character;
node `22`'s title reproduces `^1-21`'s). Each homage node splits into its own direct
identification/etymology claims (extracted as `c-N-0-*`, mirroring the vault's `N-0` heading
convention) and a `N.1` `གསལ་འདེབས་ཚུལ་` child holding the visualization instructions for that
same homage — both halves describe the one homage, so the whole node `N`'s subtree maps to
one slot. Node `23` (`གཞུང་གི་དོན་བསྡུ་བ`) glosses the root text's benefits section: its single
claim (`c-23-1`) is a word-commentary on the source file's `^0-95` root-verse quotation, which
reads `རྩ་བའི་སྔགས་ཀྱི་བསྟོད་པ་འདི་དང་། ། ཕྱག་འཚལ་བ་ནི་ཉི་ཤུ་རྩ་གཅིག` — a near-verbatim match to the
root text's own `^a-1` (`རྩ་བའི་སྔགས་ཀྱིས་བསྟོད་པ་འདི་དང་། ། ཕྱག་འཚལ་བ་ནི་ཉི་ཤུ་རྩ་གཅིག ། …`), confirming
node `23` as this commentary's (partial) treatment of the `benefits` slot. Node `0` (the raw
claims file's own pre-tree "Front matter" bucket) and the claims numbered `c-24-*` (the raw
file's own post-node-23 "Back matter" bucket, i.e. the author's colophon) are the
commentary's own front and back matter and carry no root-text content.
