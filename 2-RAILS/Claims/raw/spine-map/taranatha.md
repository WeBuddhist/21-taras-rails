# Spine map — taranatha

> Routing index only. This file records **which of this commentary's own TOC nodes hold
> which canonical spine slot's content** — nothing about what the claims say. It never
> quotes, interprets, or restates a claim; `assemble_packet.py` copies the claim text
> itself verbatim out of `2-RAILS/Claims/raw/tree-guided/taranatha.md` at packet time.
> Every claim in that file has exactly one disposition below.

**Structure of this commentary.** A flat, twenty-two-node tree with no shared "praise
proper" / "benefits" parent: top-level nodes `1`–`20` are the twenty homages, each titled
by its own ordinal plus opening words (དང་པོ་ཕྱག་འཚལ་ "first homage", གཉིས་པ་ཕྱག་འཚལ་ "second
homage", …), in exact ordinal correspondence with the root text's `^1-1`–`^1-20`. Node `21`
(ཉེར་གཅིག་པ་ཕྱག་འཚལ་དེ་ཉིད་གསུམ་རྣམས་) is announcement-only — its own claim heading is absent
("None — announcement only") — with all content in children `21.1`–`21.4`, which unpack the
twenty-first homage's four levels of meaning (literal, general, hidden, ultimate); `21.1`'s
own opening claim (c-21-1-2) quotes the root verse "ཚིགས་བཅད་ཉེར་གཅིག་པ་ཕྱག་འཚལ་དེ་ཉིད་གསུམ་
རྣམས་སོགས་ལ་" verbatim, confirming node `21`'s subtree is `^1-21`. Node `22` (འཇུག་གི་དོན་, "the
meaning of engagement") plus its child `22.1` (རྩ་བའི་སྔགས་ཀྱི་དོན་) together correspond
one-to-one to the root text's ཕན་ཡོན་ (benefits) section `^a-1`–`^a-7`: node 22's own claims
introduce the root-mantra exposition and the benefits topic (c-22-0-2 "teaches the benefits
of the praise"), and 22.1's claims run in the same order as the root verses — mantra-meaning
and recitation manner (↔ `^a-1`–`^a-2`), the empowerment/buddhahood benefit (↔ `^a-3`), the
poison benefit (↔ `^a-4`), further mantra-power benefits (↔ `^a-5`), desire-fulfillment (↔
`^a-6`), and the attribution/dedication/colophon (↔ `^a-7`). A pseudo-node `0` (front matter,
not in the TOC tree) precedes the tree's first node window and holds the commentary's own
opening title, homage to Lokeśvara, and tantra-classification material.
