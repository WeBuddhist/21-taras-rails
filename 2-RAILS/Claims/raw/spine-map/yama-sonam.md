# Spine map — yama-sonam

> Routing index only. This file records **which of this commentary's own TOC nodes hold
> which canonical spine slot's content** — nothing about what the claims say. It never
> quotes, interprets, or restates a claim; `assemble_packet.py` copies the claim text
> itself verbatim out of the raw claims file at packet time. Every claim in that file has
> exactly one disposition below.

**Structure of this commentary.** A flat, three-way top-level division: node `1` (དང་པོ་)
glosses the root text's own title/invocation block, node `2` (གཉིས་པ་) glosses its opening
salutation line, and node `3` (གསུམ་པ་ཕྱག་འཚལ་) is an announcement-only heading whose entire
content lives in twenty-one child nodes `3.1`–`3.21`, one per homage, in exact ordinal
correspondence with the root text's `^1-1`–`^1-21` — the node titles are themselves ordinals
(ཕྱག་འཚལ་དང་པོ་ "first homage", ཕྱག་འཚལ་གཉིས་པ་ "second homage", … ཕྱག་འཚལ་ཉེར་གཅིག་པ་ "twenty-first
homage"), each further naming the Tārā by epithet, and each node's own claims include a
"root verse quoted from 'the tantra'" claim confirming the correspondence (e.g. `c-3-2-3`
quotes the autumn-moon verse of `^1-2`, `c-3-3-3` quotes the golden-blue verse of `^1-3`).
The tree ends at node `3.21`; no node addresses the closing ཕན་ཡོན (benefits) section.
