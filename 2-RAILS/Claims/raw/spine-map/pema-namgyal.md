# Spine map — pema-namgyal

> Routing index only. This file records **which of this commentary's own TOC nodes hold
> which canonical spine slot's content** — nothing about what the claims say. It never
> quotes, interprets, or restates a claim; `assemble_packet.py` copies the claim text
> itself verbatim out of `2-RAILS/Claims/raw/tree-guided/pema-namgyal.md` at packet time.
> Every claim in that file has exactly one disposition below.

**Structure of this commentary.** An extremely shallow, three-way top-level tree: node `1`
(དང་པོ་སྦྱོར་བ་ཚོགས་བསགས་ཀྱི་རིམ་པ) is the commentary's own sevenfold-offering preliminary practice,
node `2` (གཉིས་པ་བསྟོད་པ་དངོས, "the actual praise") holds the title glosses (`2.1`–`2.3`) and the
entire twenty-one-homage exposition undivided in a single leaf node `2.4`
(བཞི་པ་མཚན་དོན་དངོས་བསྟན་ལྟར་གོ་སླ, "the actual meaning of the epithets, easily explained as directly
taught"), and node `3` (གསུམ་པ་མཇུག་ཕན་ཡོན་གྱི་དོན) holds the benefits section plus the commentary's
own colophon. `2.4`'s 59 claims run: a general heart-mantra/epithet exposition
(`c-2-4-1`–`c-2-4-11`, glossing OṂ TĀRE TUTTĀRE TURE SVĀHĀ and the epithets Ārya/Tārā/Heroine
in the abstract, matching no single verse), then homage-by-homage commentary from
`c-2-4-12` on, each homage's boundary attested by direct wording matches against
`1-SOURCES/Text/སྒྲོལ་མ་ཉེར་གཅིག་གི་བསྟོད་པ།.md#^1-1`–`#^1-21` (e.g. `c-2-4-12`'s "eyes… like an
instant of lightning" matches `^1-1`'s "སྤྱན་ནི་སྐད་ཅིག་གློག་དང་འདྲ་མ"; `c-2-4-16`'s "face like a hundred
autumn full moons" matches `^1-2`'s "སྟོན་ཀའི་ཟླ་བ་ཀུན་དུ་གང་བ་བརྒྱ་ནི་བརྩེགས་པའི་ཞལ་མ"), through a closing
tally (`c-2-4-57`) and two claims that fall outside any single homage (`c-2-4-58` hidden-meaning
synthesis across several verses' iconography; `c-2-4-59` a note on the source tantra's further,
unexpanded teachings). Because `2.4` is never subdivided, no node in this tree maps wholly to
one slot without also sweeping in mixed content — the Slot map below is therefore empty and
every registered slot is reached through Claim-level routing instead, exactly as the skill's
own worked example describes for an undivided node ("Node 2.1.2.1 runs all 21 homages
undivided; boundaries are the 'Verse N quoted' claims").
