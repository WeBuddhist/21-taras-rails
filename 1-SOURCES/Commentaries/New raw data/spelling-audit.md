# Spelling audit — commentaries

Checked on 2026-09-23 against the files in this folder.

Two kinds of finding are kept apart in every book:

- **Typos** — a misspelled word, a stray mark, a missing tsheg, a space inside a word.
- **Pattern inconsistency** — a particle that does not agree with the letter before it (གི / ཀྱི / གྱི, ཏུ / དུ, ཏེ / སྟེ, ཅེས / ཞེས, ཅིང / ཞིང, ཡི), or a heading that breaks the numbering pattern of its siblings.

**(?)** marks an item to confirm against the printed edition before changing it.

How this was found: automatic checks for particle agreement, for words that occur once and are one letter away from a common word, and for stray marks, missing tshegs and spaces inside words — then each flagged spot was read in context. ད་དྲག spellings (གྱུར་ཅིག, བསྣུན་ཅིང) and mantra syllables were not counted as errors. ཞེས after ས (ཚོགས་ཞེས and the like) was not flagged: strict rules want ཤེས, but ཞེས is the normal modern spelling and every file uses it. This is not a full proofread — an error that happens to form another real word will not show up.

Nothing in the files was changed.
